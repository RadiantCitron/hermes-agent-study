## 1. 구현 내용 명세

이 단계는 **동작을 바꾸지 않는 이동 리팩토링**이다. 터미널 도구 안의 작업 폴더 판정 코드를 공용 모듈로 옮겨, 이후 파일 도구가 같은 기준을 쓰게 한다.

1. **공용 모듈 신설** (`src/hermes_core/tools/path_guard.py`): 아래 세 함수를 둔다. 독스트링 상단에 원본 매핑(`hermes-agent/tools/path_security.py`의 경로 검증 도우미에 해당)을 적는다.
   - `resolve_workspace(workspace: Optional[Path]) -> Path`: `None`이면 호출 시점의 현재 폴더(`Path.cwd()`), 아니면 주어진 폴더를 `resolve()`해 반환한다. 현재 `terminal_tool`의 `base = (Path(workspace) if workspace is not None else Path.cwd()).resolve()`와 같은 동작.
   - `path_values(arg: str) -> list[str]`: 현재 `terminal_tool._path_values`와 **동일한 동작**(이름만 공개로 바꿈).
   - `is_inside(value: str, workspace: Path) -> bool`: 현재 `terminal_tool._is_inside`와 **동일한 동작**(이름만 공개로 바꿈). 풀 수 없는 경로(`OSError`, `ValueError`, `RuntimeError`)는 거짓.
2. **터미널 도구 수정** ([`terminal_tool.py`](../../../../src/hermes_core/tools/terminal_tool.py)): 비공개 함수 `_path_values`, `_is_inside`를 삭제하고 공용 모듈의 함수를 가져다 쓴다. `base`는 `resolve_workspace(workspace)`로 구한다. 오류 문구, 검사 순서, 반환 형식은 바꾸지 않는다.
3. **독스트링**: 터미널 도구 상단 독스트링의 경로 검사 설명 한 줄에 「판정은 `path_guard`」를 덧붙인다.
4. **작동원리 갱신**: 01편 [5부 ②](../../../작동원리/01-헤르메스코어-작동원리.md)와 02편 ② 항목 5(터미널 도구)에 경로 판정 코드의 새 위치(`path_guard.py`)를 추가한다. 서술의 의미는 바뀌지 않는다. `기준 커밋` 값은 건드리지 않는다 ([ROADMAP.md §7](../ROADMAP.md)).

## 3. 인수 테스트 시나리오 (구현 전 작성, 임의 변경 금지)

임시 폴더 구성: 작업 폴더 `W` 안에 `a.txt`, `sub/b.txt`, 그리고 `W` 밖의 `outside.txt`를 가리키는 링크 `link`. `outside.txt`는 `W` 밖에 있다.

| # | 입력 | 기대 결과 |
|---|---|---|
| 1 | `resolve_workspace(None)` (현재 폴더를 `W`로 바꾼 뒤) | `W.resolve()` |
| 2 | `resolve_workspace(W)` | `W.resolve()` |
| 3 | `path_values("--file=/etc/x")` | `["/etc/x"]` |
| 4 | `path_values("--long")` | `[]` |
| 5 | `path_values("-fVAL")` | `["VAL"]` |
| 6 | `path_values("-r")`, `path_values("-")` | 둘 다 `[]` |
| 7 | `path_values("plain.txt")` | `["plain.txt"]` |
| 8 | `is_inside("a.txt", W)` | 참 |
| 9 | `is_inside("../outside.txt", W)` | 거짓 |
| 10 | `is_inside("/etc/hosts", W)` | 거짓 |
| 11 | `is_inside("link", W)` (폴더 안 링크가 폴더 밖 파일을 가리킴) | 거짓 |
| 12 | `is_inside("sub/../a.txt", W)` | 참 |
| 13 | `is_inside("not/yet/created.txt", W)` (없는 경로) | 참 |
| 14 | `is_inside("~", W)` | 참 (홈 폴더로 확장하지 않음) |
| 15 | `is_inside("a\x00b", W)` (NUL 문자가 든 경로) | 거짓, 예외 없음 |
| 16 | 기존 터미널 테스트 38건 | **수정 없이** 통과 |
| 17 | `terminal_tool.py`에서 `_path_values`, `_is_inside` 검색 | 결과 없음 (정의·호출 모두 공용 모듈로 이동) |

5. 전체 `pytest tests`가 통과한다 (기존 116건 + 신규).
