## 1. 구현 내용 명세

1. **지시문 파일 이름 상수** ([`constants.py`](../../../../src/hermes_core/constants.py)):
   - `AGENTS_FILE_NAMES = ("AGENTS.md", "agents.md")`, `SOUL_FILE_NAME = "SOUL.md"`, `CURSORRULES_FILE_NAME = ".cursorrules"`
   - `INSTRUCTION_FILE_NAMES = (*AGENTS_FILE_NAMES, SOUL_FILE_NAME, CURSORRULES_FILE_NAME)`
2. **지시문 조립이 같은 상수를 쓰게 함** ([`prompt_builder.py`](../../../../src/hermes_core/agent/prompt_builder.py) `build_context_files_prompt`): 파일을 찾는 이름, 구역 제목, 절단 안내에 쓰는 이름의 리터럴(`"AGENTS.md"`, `"agents.md"`, `"SOUL.md"`, `".cursorrules"`)을 모두 위 상수로 바꾼다. **동작은 바꾸지 않는다**(탐색 순서, 구역 제목 형식, 절단 동작 동일).
3. **쓰기 경로 검사 함수 추가** (`path_guard.py`): `check_write_path(path: str, workspace: Path) -> tuple[Optional[Path], Optional[str]]`
   - 먼저 `check_path`를 호출한다. 실패하면 그 결과를 그대로 반환한다(제어문자, 작업 폴더 밖).
   - 풀린 경로의 **파일 이름**을 `casefold()`한 값이 `INSTRUCTION_FILE_NAMES`의 어느 이름을 `casefold()`한 값과 같으면 `(None, "Writing to instruction file '<이름>' is not allowed.")`.
   - 작업 폴더 **바로 아래**의 `INSTRUCTION_FILE_NAMES` 각 이름을 (링크라면 따라가) 풀었을 때 풀린 경로와 같은 파일이면 같은 문구로 거부한다. 지시문 조립이 링크를 따라 읽기 때문이다.
   - 풀린 경로가 `get_hermes_home()`을 `resolve()`한 폴더 **아래**이면 `(None, "Writing inside the Hermes state folder is not allowed.")`.
   - 모두 통과하면 `(풀린 경로, None)`.
   - **읽기 경로 검사(`check_path`)는 바꾸지 않는다.** 읽기는 막지 않는다.
4. **작동원리 갱신**: 01편 5부 ②에 `INSTRUCTION_FILE_NAMES`와 쓰기 금지 판정의 위치를 추가한다. 02편 ② 색인에도 `path_guard.py`·`constants.py` 항목을 반영한다. `기준 커밋` 값은 건드리지 않는다.

> `get_hermes_home()`은 폴더가 없으면 만든다(기존 동작). 쓰기 금지 판정이 이 부수 효과를 일으키는 것은 의도한 것이 아니므로 시나리오 9·10은 `HERMES_HOME`을 임시 폴더로 지정해 시험한다.

## 3. 인수 테스트 시나리오 (구현 전 작성, 임의 변경 금지)

작업 폴더 `W`와 `W` 밖의 `outside.txt`. 별도 표시가 없으면 `HERMES_HOME`은 `W` 밖의 임시 폴더로 지정한다. `check_write_path(path, W)`의 결과를 `(target, error)`로 쓴다.

| # | 입력 | 기대 결과 |
|---|---|---|
| 1 | `notes.txt` | `error`가 None, `target == (W/"notes.txt").resolve()` |
| 2 | `AGENTS.md` | `error`에 `instruction` 포함, `target` None |
| 3 | `sub/agents.md` | `error`에 `instruction` 포함 |
| 4 | `SOUL.md`, `.cursorrules` | 각각 `error`에 `instruction` 포함 |
| 5 | `Agents.MD` (대소문자 다름) | `error`에 `instruction` 포함 |
| 6 | `sub/new/SOUL.md` (부모 폴더가 아직 없음) | `error`에 `instruction` 포함 |
| 7 | `notes_link` (`W` 안 링크가 기존 `W/AGENTS.md`를 가리킴) | `error`에 `instruction` 포함 |
| 8 | `notes.txt` (`W/AGENTS.md`가 `W/notes.txt`를 가리키는 링크로 존재) | `error`에 `instruction` 포함 |
| 9 | `HERMES_HOME`을 `W/.hermes`로 지정하고 `.hermes/memories/MEMORY.md`, `.hermes/state.db`, `.hermes/new.txt` | 각각 `error`에 `state folder` 포함 |
| 10 | `HERMES_HOME`이 `W` 밖일 때 `.hermes/x.txt` | `error` None (이름만 같은 폴더일 뿐 상태 폴더가 아님) |
| 11 | `../x.txt` | `error`에 `outside` 포함 |
| 12 | `a\nb` | `error`에 `control` 포함 |
| 13 | 읽기: `check_path("AGENTS.md", W)`와 `check_path(".hermes/memories/MEMORY.md", W)` (`HERMES_HOME=W/.hermes`, 해당 파일이 존재), 그리고 `read_file_tool`로 두 파일 읽기 | 오류 None, `read_file_tool`은 `success` true (읽기는 허용) |

| 15 | 작업 폴더에 `NOTES.md`만 있을 때 `build_context_files_prompt(cwd)` | 빈 문자열 (목록에 없는 이름은 주입되지 않음) |
| 16 | `INSTRUCTION_FILE_NAMES` | `("AGENTS.md", "agents.md", "SOUL.md", ".cursorrules")` |
| 17 | 기존 프롬프트 빌더 테스트 5건 | **수정 없이** 통과 |
