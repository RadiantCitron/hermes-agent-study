## 1. 구현 내용 명세

1. **시스템 프롬프트 조립 모듈 (`src/hermes_core/prompt_builder.py`)**:
   - `DEFAULT_AGENT_IDENTITY`: 에이전트 기본 정체성 상수 정의
   - `build_system_prompt()`:
     - 1계층: Agent Identity
     - 2계층: 활성화된 도구 안내문 (Memory Guidance, Session Search Guidance)
     - 3계층: 사용자/호출자 지정 추가 시스템 메시지
     - 4계층: Curated Memory 스냅샷 블록 (MEMORY.md / USER.md 내용 주입)
     - 5계층: 프로젝트 컨텍스트 파일 주입 (`AGENTS.md`, `SOUL.md`, `.cursorrules`)
     - 6계층: 플랫폼 포맷팅 힌트 (CLI / Terminal)
2. **컨텍스트 파일 탐색 및 Truncation**:
   - `_truncate_content()`: 설정된 최대 글자수(기본 20,000자) 초과 시 Head(70%) + Truncation Marker + Tail(20%)로 자르는 안전장치 구현
   - `build_context_files_prompt()`: 작업 디렉터리의 `AGENTS.md` 및 `SOUL.md` 자동 탐색
3. **단위 테스트 작성**:
   - `tests/test_hermes_core/test_prompt_builder.py`:
     - 정체성 및 가이던스 포함 여부 검증
     - 긴 컨텍스트 파일의 Head/Tail 자르기 정합성 검증
     - 메모리 스냅샷이 없을 때와 있을 때의 블록 포맷 검증
