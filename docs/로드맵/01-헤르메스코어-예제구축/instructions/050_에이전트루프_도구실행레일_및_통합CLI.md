## 1. 구현 내용 명세

1. **도구 실행 단일 진입로 (`src/hermes_core/tools/`)**:
   - `dispatcher.py`: 도구 스키마 레지스트리 및 호출 디스패처
   - `base.py`: 도구 정의 인터페이스 (`ToolDefinition`)
   - 기본 탑재 도구:
     - `memory`: 030 단계에서 개발한 바운디드 메모리 도구
     - `session_search`: 040 단계에서 개발한 SQLite FTS5 검색 도구
     - `terminal`: 안전 제한 쉘 명령어 실행 도구 (위험 명령어 차단)
     - `file_ops`: 파일 읽기/쓰기 기본 도구
2. **에이전트 핵심 루프 (`src/hermes_core/agent.py`)**:
   - `HermesAgent`:
     - 세션 초기화 시 `prompt_builder`를 통해 캐시된 시스템 프롬프트 조립
     - LLM 추론 호출 ➔ `tool_calls` 감지 시 도구 실행 ➔ 결과 메시지 구성 ➔ 재추론 (최대 반복 횟수 제어)
     - 최종 답변 도출 시 세션 DB에 전체 대화 턴 저장
     - Mock LLM 클라이언트 지원 (테스트 및 오프라인 환경 대응)
3. **인터랙티브 CLI 진입점 (`src/hermes_core/main.py`)**:
   - `python -m hermes_core.main`으로 실행 가능한 터미널 REPL 인터페이스
   - 사용자 질문 입력 ➔ 에이전트 루프 동작 로그 (📞 도구 호출 미리보기) ➔ 최종 응답 출력
4. **종단간(E2E) 통합 검증 테스트**:
   - `tests/test_hermes_core/test_agent_e2e.py`:
     - Mock LLM을 사용하여 [유저 질문 ➔ 메모리 조회/추가 ➔ 세션 저장 ➔ 최종 응답] 전 사이클 자동 검증.
