## 1. 구현 내용 명세

1. **도구 오케스트레이션 및 디스패처 (`src/hermes_core/model_tools.py`)**:
   - 원본 `model_tools.py` 1:1 미러링
   - `handle_function_call(function_name, function_args, task_id=None)`: 도구 실행 단일 진입로
   - 기본 도구 연결: `memory`, `session_search`, `terminal`
2. **에이전트 핵심 루프 (`src/hermes_core/run_agent.py`)**:
   - 원본 `run_agent.py`의 `AIAgent` 클래스 1:1 미러링
   - `AIAgent`:
     - `_build_system_prompt()`: 세션 시작 시 캐시된 시스템 프롬프트 1회 조립
     - `_execute_tool_calls(assistant_message, messages)`: 도구 호출 실행 및 결과 messages 추가
     - `run_conversation(user_message, system_message=None, conversation_history=None)`: 턴 실행 루프 (최종 응답 및 messages 딕셔너리 반환)
     - Mock LLM 클라이언트 지원 (테스트 및 오프라인 환경 대응)
3. **인터랙티브 CLI 진입점 (`src/hermes_core/cli.py`)**:
   - 원본 `cli.py` 미러링
   - `python -m hermes_core.cli`로 실행 가능한 터미널 대화형 루프
   - 사용자 질문 입력 ➔ 에이전트 루프 동작 로그 (`📞 Tool: ...`) ➔ 최종 응답 출력
4. **종단간(E2E) 통합 검증 테스트**:
   - `tests/test_hermes_core/test_agent_e2e.py`:
     - Mock LLM을 사용하여 [유저 질문 ➔ 메모리 조회/추가 ➔ 세션 저장 ➔ 최종 응답] 전 사이클 자동 검증.
