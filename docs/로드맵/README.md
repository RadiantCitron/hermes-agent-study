| 07 | **서브에이전트 MVP** | 06까지의 코어에 순차 단일 자식 서브에이전트를 더한다. `delegate_task`로 일을 넘기면 자식이 새 대화·제한된 도구(위임·기억·과거 검색 제외)·분리된 호출 원장으로 일하고 길이 상한이 있는 요약만 돌려준다. 병렬·중첩·백그라운드·중단 전파는 제외 | [07-대시보드](07-서브에이전트-MVP/README.md) | [07-마스터설계도](07-서브에이전트-MVP/ROADMAP.md) |
| 08 | **스킬 인덱스 주입 MVP** | 07까지의 코어에서 스킬을 도구로만 꺼내 읽을 때 모델에 따라 호출 여부가 갈린 관찰(deepseek 미호출, Gemini Flash 호출)을 근거로, 세션 시작 때 스킬의 이름·한 줄 설명을 시스템 지시문에 한 번 고정해 넣는다. 설명 텍스트는 줄바꿈·구획 문자 제거와 3중 길이 상한으로 가두고 자식에는 넣지 않는다. 위임은 고치지 않고 관찰만 | [08-대시보드](08-스킬-인덱스-주입-MVP/README.md) | [08-마스터설계도](08-스킬-인덱스-주입-MVP/ROADMAP.md) |

| 10 | **승인 흐름 MVP** | 09까지의 코어에서 허용목록 8개 밖의 터미널 명령을 영구 거부하는 대신, 사람이 실행될 `argv`를 보고 예/아니오로 승인했을 때만 실행한다. 승인 요청은 묻기 전에 상태 DB에 남기고, 승인기가 없는 구성(라이브러리 기본·위임 자식·비터미널)은 지금처럼 거부하며, 보호 파일(`.env*`·`.git`)은 승인해도 막는다. 영구 허용목록·위험 패턴·파일 도구 승인은 제외. 이후 11 체크포인트·롤백은 직전 로드맵 마감 후 계획 | [10-대시보드](10-승인-흐름-MVP/README.md) | [10-마스터설계도](10-승인-흐름-MVP/ROADMAP.md) |
| 11 | **체크포인트·롤백 MVP** | 10까지의 코어에서 파일 도구(`write_file`·`patch`)가 바꾸기 전 모습(「없었음」 또는 원래 텍스트)을 상태 DB에 먼저 적고, 사람이 CLI `/rollback`으로 최근 턴부터 차례로 되돌린다. 적지 못하면 쓰지 않고, 그사이 다른 손이 고친 파일은 건너뛰고 알린다. 라이브러리 기본 꺼짐·CLI 기본 켜짐(`--no-checkpoints`). 터미널 변경·위임 자식·모델 알림·그림자 git 저장소는 제외 | [11-대시보드](11-체크포인트-롤백-MVP/README.md) | [11-마스터설계도](11-체크포인트-롤백-MVP/ROADMAP.md) |
