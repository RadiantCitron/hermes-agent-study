## 1. 구현 내용 명세

설정 변경(`SetSetting`)과 확장 켜기·끄기(`EnableExtension`, `DisableExtension`)를 불변 명령 객체로 표현하고, **검증 → 감사 선기록(`control_audit` 표, DB 스키마 v7) → 대기열 적재 → 다음 턴 시작 직전 반영(`apply_pending`)**의 단일 경로로만 상태를 바꾸는 `hermes_core.control.commands`와 `hermes_core.control.panel`을 신설한다. 보안 설정(`locked`)과 시작 전용 설정(`startup`) 변경 시도는 검증에서 거부하고 거부 사실까지 감사 장부에 남기며, 감사 기록 호출이 실패하면 대기열 적재나 상태 반영을 하지 않는다(WHY 가정 F·G).

### 1-1. `src/hermes_core/session_db.py` (변경) — 스키마 v7 및 `control_audit` 원장

- **`SCHEMA_VERSION = 7`** (36행 `6` → `7`).
- **`SCHEMA_SQL`에 `control_audit` 표 및 인덱스 추가**:
  ```sql
  CREATE TABLE IF NOT EXISTS control_audit (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      session_id TEXT NOT NULL REFERENCES sessions(id),
      created_at REAL NOT NULL,
      source TEXT NOT NULL,
      command TEXT NOT NULL,
      target TEXT NOT NULL,
      old_value TEXT,
      new_value TEXT,
      result TEXT NOT NULL,
      reason TEXT
  );
  ```
  그리고 인덱스 선언부에 `CREATE INDEX IF NOT EXISTS idx_control_audit_session ON control_audit(session_id, id);`를 더한다.
- **`_init_schema` 마이그레이션 추가** (213행 뒤):
  ```python
  if current_version < 7:
      cursor.execute("UPDATE schema_version SET version = 7")
  ```
- **`SessionDB` 감사 원장 메서드 2개 신설** (파일 하단 `get_file_checkpoints` 뒤):
  - 허용 상수(모듈 내부 또는 검증용):
    - 허용 `source`: `("cli", "breaker")` (단, 빈 문자열이 아닌 `str`이면 허용하되 공백만 있거나 `str`이 아니면 `ValueError`)
    - 허용 `command`: `("set_setting", "enable_extension", "disable_extension")`
    - 허용 `result`: `("accepted", "rejected", "applied")`
  - `record_control_audit`:
    ```python
    def record_control_audit(
        self,
        session_id: str,
        *,
        source: str,
        command: str,
        target: str,
        old_value: Optional[str] = None,
        new_value: Optional[str] = None,
        result: str,
        reason: Optional[str] = None,
    ) -> int:
    ```
    - 인자 검증(하나라도 어기면 `ValueError`, 행 미생성):
      - `session_id`, `source`, `target`은 빈 문자열이 아닌(`strip() != ""`) `str`.
      - `command`는 `("set_setting", "enable_extension", "disable_extension")` 중 하나.
      - `result`는 `("accepted", "rejected", "applied")` 중 하나.
      - `old_value`, `new_value`, `reason`은 `None`이거나 `str`.
    - `INSERT INTO control_audit (session_id, created_at, source, command, target, old_value, new_value, result, reason) VALUES (?, ?, ?, ?, ?, ?, ?, ?, ?)`를 실행하고 즉시 `self._conn.commit()`한 뒤 `int(cursor.lastrowid)`를 반환한다. (존재하지 않는 `session_id`는 SQLite 외래키 제약에 의해 `sqlite3.IntegrityError`가 발생한다.)
  - `list_control_audit`:
    ```python
    def list_control_audit(self, session_id: str) -> list[dict[str, Any]]:
    ```
    - `SELECT * FROM control_audit WHERE session_id = ? ORDER BY id ASC` 결과를 `[dict(row) for row in cursor.fetchall()]`로 반환한다.

### 1-2. `src/hermes_core/control/commands.py` (신규) — 쓰기 명령과 검증기

- **패키지 의존 규칙 (R6 준수)**: 표준 라이브러리(`dataclasses`, `typing`)와 `hermes_core.control.settings`(`SETTING_SPECS`, `LoadedSettings`)만 import한다.
- **불변 명령 데이터 클래스 (`@dataclass(frozen=True)`)**:
  ```python
  @dataclass(frozen=True)
  class SetSetting:
      """런타임 설정 변경 명령."""

      key: str
      value: Any


  @dataclass(frozen=True)
  class EnableExtension:
      """확장 활성화 명령."""

      name: str


  @dataclass(frozen=True)
  class DisableExtension:
      """확장 비활성화 명령."""

      name: str


  ControlCommand = Union[SetSetting, EnableExtension, DisableExtension]
  ```
- **거부 사유 코드 및 결과 데이터 클래스**:
  ```python
  RejectionCode = Literal[
      "unknown_key",
      "bad_value",
      "locked",
      "startup_only",
      "unknown_extension",
  ]


  @dataclass(frozen=True)
  class Rejection:
      """명령 검증 거부 결과."""

      code: RejectionCode
      message: str
  ```
- **명령 검증 함수 (`validate_command`)**:
  ```python
  def validate_command(
      cmd: ControlCommand,
      loaded: LoadedSettings,
      extension_names: Collection[str],
  ) -> Optional[Rejection]:
  ```
  - `isinstance(cmd, SetSetting)`일 때:
    1. `cmd.key not in SETTING_SPECS`이면 `Rejection("unknown_key", f"Unknown setting key: '{cmd.key}'")` 반환.
    2. `spec = SETTING_SPECS[cmd.key]`.
    3. `spec.mutability == "locked"`이면 `Rejection("locked", f"Setting '{cmd.key}' is locked and cannot be changed")` 반환(보안 설정 하향 원천 차단 — ADR D-08, ROADMAP §4 위험 8).
    4. `spec.mutability == "startup"`이면 `Rejection("startup_only", f"Setting '{cmd.key}' can only be set at startup")` 반환.
    5. `spec.validator(cmd.value)`를 실행한다. `Exception`이 발생하면 `Rejection("bad_value", str(exc))` 반환.
    6. 통과하면 `None` 반환.
  - `isinstance(cmd, (EnableExtension, DisableExtension))`일 때:
    1. `if not isinstance(cmd.name, str) or cmd.name not in extension_names:`이면 `Rejection("unknown_extension", f"Unknown extension: '{cmd.name}'")` 반환.
    2. 통과하면 `None` 반환.
  - 그 밖의 타입이면 `TypeError("Unsupported control command")`를 던진다.

### 1-3. `src/hermes_core/assembly.py` (변경) — `apply_runtime_settings`

- `RUNTIME_SETTING_KEYS: tuple[str, ...] = ("max_iterations", "context_window_tokens", "compression_enabled", "compression_threshold_ratio", "breaker_threshold")`.
- `apply_runtime_settings(agent: Any, settings: Settings, *, changed_keys: Optional[Collection[str]] = None) -> None` 신설:
  - **다층 방어 (ROADMAP §4 위험 8)**:
    - `changed_keys`가 주어졌을 때, 각 `k`에 대해 `k not in SETTING_SPECS`이거나 `SETTING_SPECS[k].mutability != "runtime"`(`"locked"` 또는 `"startup"`)이면 즉시 `ValueError(f"Setting '{k}' is not runtime-mutable")`를 던지고 아무 속성도 바꾸지 않는다.
    - `settings`의 모든 키에 대해 `SETTING_SPECS[k].validator(getattr(settings, k))`를 확인하여 무효값이면 `ValueError`를 던진다.
  - 반영할 대상 키(`target_keys = set(changed_keys) if changed_keys is not None else set(RUNTIME_SETTING_KEYS)`)에 따라 에이전트에 반영한다:
    - `"max_iterations" in target_keys`: `agent.max_iterations = settings.max_iterations`
    - `"context_window_tokens" in target_keys`: `agent.context_window_tokens = settings.context_window_tokens`
    - `"compression_enabled" in target_keys`: `agent.compression_enabled = settings.compression_enabled`
    - `"compression_threshold_ratio" in target_keys`: `agent.compression_threshold_ratio = settings.compression_threshold_ratio`
    - `"breaker_threshold" in target_keys`: `agent.set_extension_breaker(settings.breaker_threshold)` (030 지시서 §5)

### 1-4. `src/hermes_core/control/panel.py` (신규) — `ControlPanel`

- **패키지 의존 규칙 (R6 준수)**: 표준 라이브러리(` collections`, `dataclasses`, `typing`), `hermes_core.control.commands`, `hermes_core.control.settings`, `hermes_core.control.snapshot`만 import한다(`assembly`나 `agent`나 `session_db`는 import하지 않는다).
- **제출 및 반영 결과 데이터 클래스 (`@dataclass(frozen=True)`)**:
  ```python
  @dataclass(frozen=True)
  class SubmitResult:
      """submit() 호출 결과."""

      accepted: bool
      command: ControlCommand
      audit_id: int
      rejection: Optional[Rejection] = None


  @dataclass(frozen=True)
  class AppliedChange:
      """apply_pending()에서 실제 반영된 단일 명령 결과."""

      command: ControlCommand
      old_value: str
      new_value: str
      audit_id: int
  ```
- **값 문자열화 및 마스킹 도우미 (`_format_audit_value`)**:
  - `val is None`이면 `None`을 반환하고, 아니면 `mask_secrets(str(val))`를 반환한다(ROADMAP §6-4: 장부 값 열에 쓰기 전에 `mask_secrets` 적용).
- **기본 런타임 설정 반영 도우미 (`_default_apply_runtime_settings(agent: Any, settings: Settings, changed_keys: Collection[str]) -> None`)**:
  - R6에 의해 `control/panel.py`는 `assembly`를 직접 import하지 않으므로, `apply_settings_fn`이 주입되지 않았을 때도 단독 동작하도록 동일한 다층 방어(`SETTING_SPECS[k].mutability != "runtime"`이면 `ValueError`)와 5개 런타임 키 반영(`agent.max_iterations`, `agent.context_window_tokens`, `agent.compression_enabled`, `agent.compression_threshold_ratio`, `agent.set_extension_breaker(settings.breaker_threshold)`)을 수행한다. (`cli.py`에서는 `assembly.apply_runtime_settings`를 넘겨 연결한다.)
- **`ControlPanel` 클래스**:
  ```python
  class ControlPanel:
      """단일 제어판: 명령 검증, 감사 선기록, 대기열 관리, 턴 경계 반영, 스냅샷 조회."""

      def __init__(
          self,
          agent: Any,
          loaded: LoadedSettings,
          session_db: Any,
          *,
          apply_settings_fn: Optional[Callable[[Any, Settings], None]] = None,
      ) -> None:
  ```
  - 내부 상태:
    - `self._agent = agent`
    - `self._loaded = loaded`
    - `self._session_db = session_db`
    - `self._apply_settings_fn = apply_settings_fn`
    - `self._queue: deque[tuple[ControlCommand, str]] = deque()` (`(cmd, source)` 쌍)
  - 프로퍼티:
    - `loaded -> LoadedSettings`: 현재 `self._loaded` 반환.
    - `pending_count -> int`: `len(self._queue)` 반환.
  - 확장 이름 목록 및 현재 상태 조회 내부 도우미:
    - `extension_status()`가 있으면 그 이름들과 `enabled` 값을 쓰고, 없으면 `agent.extensions`의 이름들을 순서대로 중복 없이 쓴다.
  - **`submit(self, cmd: ControlCommand, *, source: str = "cli") -> SubmitResult`**:
    1. 현재 설치된 확장 이름 목록을 구해 `rejection = validate_command(cmd, self._loaded, ext_names)`를 실행한다.
    2. 감사 기록에 쓸 `(command_name, target, old_val_str, new_val_str)`를 계산한다:
       - `SetSetting(key, value)`:
         - `command_name = "set_setting"`, `target = cmd.key`
         - `old_raw = getattr(self._loaded.settings, cmd.key, None)` (모르는 키면 `None`)
         - `old_val_str = _format_audit_value(old_raw)`
         - `new_val_str = _format_audit_value(SETTING_SPECS[cmd.key].validator(cmd.value) if rejection is None else cmd.value)`
       - `EnableExtension(name)` / `DisableExtension(name)`:
         - `command_name = "enable_extension"` 또는 `"disable_extension"`, `target = cmd.name`
         - 아는 확장이면 현재 켜짐 여부(`"true"` 또는 `"false"`), 모르는 확장이면 `None`을 `old_val_str`로 둔다.
         - `new_val_str = "true"`(`EnableExtension`) 또는 `"false"`(`DisableExtension`).
    3. `rejection is not None`이면:
       - `audit_id = self._session_db.record_control_audit(self._agent.session_id, source=source, command=command_name, target=target, old_value=old_val_str, new_value=new_val_str, result="rejected", reason=f"{rejection.code}: {rejection.message}")`를 호출한다.
       - 대기열(`self._queue`)에는 넣지 않고 `SubmitResult(accepted=False, command=cmd, audit_id=audit_id, rejection=rejection)`를 반환한다.
    4. `rejection is None`이면:
       - **감사 선기록 (ROADMAP §4 위험 7, WHY 가정 G)**: 먼저 `audit_id = self._session_db.record_control_audit(self._agent.session_id, source=source, command=command_name, target=target, old_value=old_val_str, new_value=new_val_str, result="accepted", reason=None)`를 호출한다.
       - 위 기록 호출이 예외 없이 끝난 뒤에만 `self._queue.append((cmd, source))`로 대기열에 넣는다(기록 실패 시 예외가 전파되고 대기열 길이는 그대로 유지됨).
       - `SubmitResult(accepted=True, command=cmd, audit_id=audit_id, rejection=None)`를 반환한다.
  - **`apply_pending(self) -> list[AppliedChange]`**:
    - 대기열(`self._queue`)에 쌓인 명령들을 FIFO 순서대로 하나씩 꺼내 처리한다.
    - 각 `(cmd, source)`마다:
      - `isinstance(cmd, SetSetting)`일 때:
        1. `spec = SETTING_SPECS[cmd.key]`
        2. `if spec.mutability != "runtime": raise ValueError(f"Cannot apply non-runtime setting: {cmd.key}")` (다층 방어).
        3. `valid_val = spec.validator(cmd.value)`
        4. `old_raw = getattr(self._loaded.settings, cmd.key)`
        5. `old_str = _format_audit_value(old_raw)`, `new_str = _format_audit_value(valid_val)`
        6. **감사 선기록**: `audit_id = self._session_db.record_control_audit(self._agent.session_id, source=source, command="set_setting", target=cmd.key, old_value=old_str, new_value=new_str, result="applied", reason=None)`를 먼저 호출한다. (여기서 예외가 나면 해당 명령을 대기열 맨 앞에 되돌려 놓고 에이전트와 `self._loaded`는 바꾸지 않은 채 예외를 던진다.)
        7. `new_settings = dataclasses.replace(self._loaded.settings, **{cmd.key: valid_val})`
        8. `new_sources = dict(self._loaded.sources)` 후 `new_sources[cmd.key] = "cli" if source in ("cli", "default", "file", "env") else "cli"`(출처가 `"default" | "file" | "env" | "cli"`이면 그 값, 아니면 `"cli"`).
        9. `if self._apply_settings_fn is not None: self._apply_settings_fn(self._agent, new_settings)` 아니면 `_default_apply_runtime_settings(self._agent, new_settings, (cmd.key,))`를 호출한다.
        10. `self._loaded = LoadedSettings(settings=new_settings, sources=new_sources, file_path=self._loaded.file_path)`.
        11. `applied_list.append(AppliedChange(command=cmd, old_value=old_str or "", new_value=new_str or "", audit_id=audit_id))`.
      - `isinstance(cmd, (EnableExtension, DisableExtension))`일 때:
        1. `target_enabled = isinstance(cmd, EnableExtension)`
        2. `cmd_name = "enable_extension" if target_enabled else "disable_extension"`
        3. 현재 해당 확장의 `enabled` 상태를 읽어 `old_str = "true" if cur_enabled else "false"`, `new_str = "true" if target_enabled else "false"`.
        4. **감사 선기록**: `audit_id = self._session_db.record_control_audit(self._agent.session_id, source=source, command=cmd_name, target=cmd.name, old_value=old_str, new_value=new_str, result="applied", reason=None)`를 먼저 호출한다(실패 시 대기열 복원 후 예외 전파, 에이전트 무변경).
        5. `self._agent.set_extension_enabled(cmd.name, target_enabled)`를 호출한다.
        6. `applied_list.append(AppliedChange(command=cmd, old_value=old_str, new_value=new_str, audit_id=audit_id))`.
    - `applied_list`를 반환한다.
  - **`snapshot(self) -> ControlSnapshot`**:
    - `build_snapshot(self._agent, self._loaded, pending=len(self._queue))`를 반환한다.

- **050에서의 CLI `/ctl` 분기 연결**: 이 단계(040)에서 `cli.py`에 `panel = ControlPanel(...)` 생성과 턴 직전 `panel.apply_pending()` 호출까지 연결해 두었으므로, 050에서는 `/rollback` 분기 옆에 `if tokens and tokens[0].lower() == "/ctl": _handle_ctl(tokens, panel); continue`와 안내 상수(`CLI_CTL_*`)만 추가하면 된다.
- **050에서의 문자열 설정값 파싱**: 사용자가 `/ctl set <key> <value>`를 입력했을 때, `<key>`가 `SETTING_SPECS`에 있으면 `parse_setting_string(key, raw_value)`(010에서 구현 완료)를 호출하여 타입 변환을 시도하되, 변환 실패(`ValueError`)더라도 감사 기록(`rejected/bad_value`)이 남도록 `SetSetting(key, raw_value)`를そのまま `panel.submit(...)`에 넘길지, 아니면 `parse_setting_string`에서 나온 값을 넘길지는 050 지시서에서 정한다(참고: `SetSetting(key, raw_value)`를 그대로 `panel.submit`에 넘기면 `spec.validator(raw_value)`가 실패하여 `panel.submit`이 자동으로 `rejected/bad_value` 감사 기록을 남긴다).
