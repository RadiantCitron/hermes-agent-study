## 1. 구현 내용 명세

`HermesAgent`의 `_ExtensionHost`가 도구 미들웨어와 턴 훅을 등록할 때 **게이트(문)**로 감싸고, 확장별 켜짐 상태(`enabled`)·연속 실패 수(`consecutive_failures`)·차단 여부(`tripped`)를 `HermesAgent`가 소유·관리한다. 연속 실패 수가 `breaker_threshold`(> 0)에 도달하면 해당 확장을 즉시 끄고 `EVENT_EXTENSION_TRIPPED` 이벤트를 방출한다. 커널(`kernel/`)과 디스패처(`tools/dispatcher.py`)는 한 줄도 고치지 않는다(WHY 가정 C).

### 1-1. `src/hermes_core/agent/events.py` (변경)

- `EVENT_EXTENSION_TRIPPED = "extension_tripped"` 상수를 정의하고 `__all__`에 `"EVENT_EXTENSION_TRIPPED"`를 추가한다.

### 1-2. `src/hermes_core/agent/agent.py` (변경)

- **상수 및 상태 데이터 클래스**:
  - `EVENT_EXTENSION_TRIPPED = "extension_tripped"` (값은 `hermes_core.agent.events.EVENT_EXTENSION_TRIPPED`와 동일한 `"extension_tripped"`).
  - 동결 데이터 클래스 `ExtensionStatus`:
    ```python
    @dataclass(frozen=True)
    class ExtensionStatus:
        """설치된 확장의 켜짐 여부, 연속 실패 수, 차단 상태(읽기 전용)."""

        name: str
        enabled: bool
        consecutive_failures: int
        tripped: bool
    ```
- **게이트 도우미 함수 (`_gate_middleware`, `_gate_turn_hook`)**:
  - 표준 라이브러리 `copy`와 `functools`를 import한다(`hasattr`는 사용하지 않는다).
  - 도구 미들웨어 게이트:
    ```python
    def _gate_middleware(
        agent: "HermesAgent",
        name: str,
        middleware: Callable[..., Any],
    ) -> Callable[..., Any]:
        @functools.wraps(middleware)
        def gated(call: Any, next_fn: Callable[..., Any]) -> Any:
            if not agent._extension_enabled.get(name, True):
                return next_fn(call)
            result = middleware(call, next_fn)
            agent._extension_succeeded(name)
            return result

        if getattr(middleware, "__name__", None) is None:
            gated.__name__ = type(middleware).__name__
        return gated
    ```
    - 확장이 꺼져 있으면 `middleware`를 부르지 않고 `next_fn(call)`을 그대로 반환한다(성공·실패 수 변화 없음).
    - 확장이 켜져 있으면 `middleware(call, next_fn)`을 호출한다. 예외는 잡지 않고 그대로 전파하여 `ToolDispatcher`의 `mw_exc is inner_exc` 판정과 단계별 실패 정책(`OPEN`/`CLOSED`)을 보존한다(위험 1).
    - 예외 없이 반환되면 `agent._extension_succeeded(name)`로 연속 실패 수를 `0`으로 초기화하고 결과를 반환한다(위험 2).
  - 턴 훅 게이트:
    ```python
    def _gate_turn_hook(
        agent: "HermesAgent",
        name: str,
        hook: Callable[..., Any],
    ) -> Callable[..., Any]:
        @functools.wraps(hook)
        def gated(ctx: Any) -> None:
            if not agent._extension_enabled.get(name, True):
                return None
            before = copy.deepcopy(ctx.messages)
            hook(ctx)
            if ctx.messages == before:
                agent._extension_succeeded(name)
            return None

        if getattr(hook, "__name__", None) is None:
            gated.__name__ = type(hook).__name__
        return gated
    ```
    - 확장이 꺼져 있으면 `hook`을 부르지 않고 `None`을 반환한다.
    - 확장이 켜져 있으면 호출 전 `before = copy.deepcopy(ctx.messages)`를 잡아 두고 `hook(ctx)`를 실행한다. 예외는 잡지 않는다. 예외 없이 끝나고 `ctx.messages == before`일 때만 `agent._extension_succeeded(name)`를 호출한다.
- **`HermesAgent` 초기화 및 메서드**:
  - `__init__`의 확장 관리자 초기화 블록(215~220행 부근, `for ext in target_extensions: self.install_extension(ext)` 직전)에 아래 상태 필드를 추가한다:
    - `self._extension_enabled: dict[str, bool] = {}`
    - `self._extension_consecutive_failures: dict[str, int] = {}`
    - `self._extension_tripped: dict[str, bool] = {}`
    - `self._breaker_threshold: int = 0` (라이브러리 기본값 `0` = 차단기 꺼짐, ADR-0019 D-07)
  - `install_extension(self, ext: Extension) -> None`:
    - `self._installed_extensions.append(ext)` 직후 `ext.install(host)` 호출 전에 초기 상태를 세팅한다:
      - `self._extension_enabled[ext.name] = True`
      - `self._extension_consecutive_failures[ext.name] = 0`
      - `self._extension_tripped[ext.name] = False`
  - `_extension_succeeded(self, name: str) -> None`:
    - `self._extension_consecutive_failures[name] = 0`
  - `_on_extension_error(self, name: str, slot: str, exc: Exception) -> None`:
    - 기존 누적 실패 수(`self._extension_failures[name]`) 증가, 경고 로그, `EVENT_EXTENSION_ERROR` 방출을 그대로 수행한 뒤:
    - 연속 실패 수를 1 올린다: `consec = self._extension_consecutive_failures.get(name, 0) + 1`, `self._extension_consecutive_failures[name] = consec`.
    - 만약 `self._breaker_threshold > 0`이고 `self._extension_enabled.get(name, True)`가 `True`이며 `consec >= self._breaker_threshold`이면:
      - `self._extension_enabled[name] = False`
      - `self._extension_tripped[name] = True`
      - `logger.warning("Extension '%s' tripped circuit breaker after %d consecutive failures.", name, consec)`
      - `self._emit(EVENT_EXTENSION_TRIPPED, name=name, failures=consec)`
  - `set_extension_enabled(self, name: str, enabled: bool) -> None`:
    - `if not isinstance(enabled, bool): raise ValueError("enabled must be a bool.")`
    - 설치된 확장인지 확인한다(`if not any(e.name == name for e in self._installed_extensions): raise ValueError(f"Unknown extension '{name}'.")`).
    - `self._extension_enabled[name] = enabled`
    - `if enabled:`이면 `self._extension_consecutive_failures[name] = 0` 및 `self._extension_tripped[name] = False`로 초기화한다(ROADMAP §2-6·§6-3). `else:`(수동 끄기)이면 `self._extension_tripped[name] = False`로 둔다(차단에 의한 꺼짐이 아닌 사람에 의한 꺼짐).
  - `extension_status(self) -> tuple[ExtensionStatus, ...]`:
    - `self._installed_extensions` 설치 순서대로 각 확장의 `ExtensionStatus(name=ext.name, enabled=self._extension_enabled.get(ext.name, True), consecutive_failures=self._extension_consecutive_failures.get(ext.name, 0), tripped=self._extension_tripped.get(ext.name, False))`를 튜플로 반환한다.
  - `set_extension_breaker(self, threshold: int) -> None`:
    - `if isinstance(threshold, bool) or not isinstance(threshold, int) or threshold < 0: raise ValueError("threshold must be an integer >= 0.")`
    - `self._breaker_threshold = threshold`
- **`_ExtensionHost` 변경**:
  - `add_tool_middleware`: `gated = _gate_middleware(self._agent, self._extension_name, middleware)`를 만들어 `self._agent.dispatcher.add_middleware(gated, phase=phase, name=self._extension_name)`에 넘긴다.
  - `add_turn_hook`: `gated = _gate_turn_hook(self._agent, self._extension_name, hook)`를 만들어 `self._agent.hooks.register(point, gated, name=self._extension_name)`와 `self._agent._hook_to_extension[id(gated)] = self._extension_name`에 **같은 `gated` 객체**를 등록한다(위험 3).
