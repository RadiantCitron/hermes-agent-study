1. **기준 코드 대조** (기준: `main` `1a653b8`, `src`·`tests`는 `8fbde6b`와 같음): 아래 사실이 지금 코드와 같은지 연다. 다르면 멈추고 보고한다.

## 1. 구현 내용 명세

에이전트(`agent`)와 설정 출처(`LoadedSettings`)로부터 현재 상태를 읽기 전용 동결 스냅샷(`ControlSnapshot`)으로 조립하는 `hermes_core.control.snapshot` 모듈을 신설한다. 스냅샷 생성과 렌더링은 에이전트 속성이나 세션 DB를 일체 변경하지 않으며(WHY 가정 H), 문자열 값이나 텍스트에 섞인 비밀값 패턴을 가리는 `mask_secrets`를 함께 제공한다(040 감사 기록에서도 재사용).

### 1-1. `src/hermes_core/control/snapshot.py` (신규)

- **패키지 의존 규칙 (R6 준수)**: 표준 라이브러리(`dataclasses`, `re`, `typing`)와 `hermes_core.control.settings`(`SETTING_SPECS`, `LoadedSettings`, `Mutability`, `SettingSource`)만 import한다. `hermes_core.agent`·`hermes_core.kernel`·`hermes_core.session_db`는 import하지 않으며, `build_snapshot`의 `agent` 인자 타입은 `Any`로 둔다(`test_dependency_rules.py` R6 및 `test_annotations_resolve.py` 정합).
- **비밀값 마스킹 (`mask_secrets`)**:
  ```python
  def mask_secrets(text: str) -> str:
  ```
  - 입력 `text`에서 아래 패턴을 `"***"`로 치환한 새 문자열을 반환한다:
    1. **Bearer 토큰**: `(?i)\b(Bearer\s+)[^\s"',;)]+` → 접두부(`Bearer `)는 유지하고 토큰 부분만 `***`로 치환(`r"\1***"`).
    2. **OpenRouter 및 `sk-` 계열 키**: `\bsk-[A-Za-z0-9_-]{8,}\b` → `"***"` (`sk-or-v1-...`를 포함해 `sk-` 뒤에 영숫자·밑줄·하이픈이 8자 이상 이어지는 토큰 전체를 `"***"`로 치환).
  - 문자열에 해당 패턴이 없으면 원문 그대로 반환한다.
- **스냅샷 데이터 모델 (모두 `@dataclass(frozen=True)`)**:
  - `class SettingView`:
    - `key: str`
    - `value: Any` (문자열이면 `mask_secrets(value)`를 거친 값, 그 밖의 `int`·`float`·`bool`·`None`은 그대로)
    - `source: SettingSource` (`"default" | "file" | "env" | "cli"`)
    - `mutability: Mutability` (`"runtime" | "startup" | "locked"`)
  - `class ExtensionView`:
    - `name: str`
    - `kinds: tuple[str, ...]` (해당 확장이 등록한 `kind`들을 등록 순서대로 중복 없이 묶은 튜플. 예: `("turn_hook",)` 또는 `("tool_middleware",)`)
    - `slots: tuple[str, ...]` (해당 확장이 등록한 `slot`들을 등록 순서대로 중복 없이 묶은 튜플. 예: `("before_llm",)` 또는 `("GUARD",)`)
    - `total_failures: int` (`ExtensionRecord.failures` 값)
    - *(참고: 030에서 `enabled: bool`, `consecutive_failures: int`, `tripped: bool` 필드가 이 클래스 끝에 추가된다 — ROADMAP §6-2·§6-3)*
  - `class ControlSnapshot`:
    - `settings: tuple[SettingView, ...]`
    - `extensions: tuple[ExtensionView, ...]`
    - `session_id: str`
    - `input_tokens: int`
    - `output_tokens: int`
    - `pending_commands: int`
- **스냅샷 조립 함수 (`build_snapshot`)**:
  ```python
  def build_snapshot(
      agent: Any,
      loaded: LoadedSettings,
      *,
      pending: int = 0,
  ) -> ControlSnapshot:
  ```
  - `pending < 0`이면 `ValueError("pending must be >= 0")`를 던진다.
  - **설정 뷰 조립 (`settings`)**:
    - `SETTING_SPECS`의 키 순서(12개)대로 순회한다.
    - 값 `raw_val = getattr(loaded.settings, key)`를 읽고, `isinstance(raw_val, str)`이면 `val = mask_secrets(raw_val)`, 아니면 `val = raw_val`로 둔다.
    - 출처 `source = loaded.sources.get(key, "default")`, 변경 가능 시점 `mutability = spec.mutability`로 `SettingView(key=key, value=val, source=source, mutability=mutability)`를 만든다.
  - **확장 뷰 조립 (`extensions`)**:
    - `getattr(agent, "extensions", ())`를 순회하며 확장 `rec.name`별로 처음 등장한 순서를 유지해 묶는다.
    - 같은 `name`의 레코드들에서 `rec.kind`를 등장 순서대로 중복 없이 모아 `tuple`로 만들고(`kinds`), `rec.slot`도 등장 순서대로 중복 없이 모아 `tuple`로 만든다(`slots`). `total_failures`는 `int(rec.failures)`로 둔다.
  - **세션 및 토큰 합계 조회 (`session_id`, `input_tokens`, `output_tokens`)**:
    - `session_id = str(getattr(agent, "session_id", ""))`.
    - `session_db = getattr(agent, "session_db", None)`. `session_db is not None`이고 `session_id`가 비어 있지 않으면 `row = session_db.get_session(session_id)`를 호출한다.
    - `row`가 사전이면 `input_tokens = int(row.get("input_tokens") or 0)`, `output_tokens = int(row.get("output_tokens") or 0)`로 읽고, `row is None`이거나 `session_db is None`이면 둘 다 `0`으로 둔다.
  - 조립된 `ControlSnapshot`을 반환한다. 이 과정에서 에이전트나 `session_db`의 상태를 바꾸는 메서드는 일체 호출하지 않는다.
- **스냅샷 문자열 렌더링 (`render_snapshot`)**:
  ```python
  def render_snapshot(snapshot: ControlSnapshot) -> str:
  ```
  - 사람이 읽기 쉬운 여러 줄 문자열을 만들어 마지막에 `mask_secrets(...)`를 한 번 더 거쳐(다층 방어, ADR D-05·ROADMAP §4 위험 9) 반환한다.
  - 포함해야 할 정보:
    - 헤더/세션 줄: `session_id`, `input_tokens`, `output_tokens`, `pending_commands`.
    - 설정 섹션: `snapshot.settings`의 각 `SettingView`마다 `key`, `value`, `source`, `mutability`가 한 줄씩 나타난다.
    - 확장 섹션: `snapshot.extensions`가 비어 있으면 `(none)`을 표시하고, 있으면 각 `ExtensionView`마다 `name`, `kinds`(쉼표 연결), `slots`(쉼표 연결), `failures={total_failures}`가 한 줄씩 나타난다.
