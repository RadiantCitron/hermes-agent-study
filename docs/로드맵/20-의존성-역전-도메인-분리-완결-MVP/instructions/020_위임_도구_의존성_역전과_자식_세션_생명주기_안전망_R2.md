### 1.1 `src/hermes_core/assembly.py` 수정: 기본 자식 실행기 조립 (D-04, R-2)

1. 필요한 표준 라이브러리 및 상수, 포트 import 추가:
   - `import uuid`
   - `from hermes_core.constants import DELEGATE_CHILD_MAX_ITERATIONS, SUBAGENT_SOURCE`
   - `from hermes_core.tools.ports import ChildRunnerPort`
2. `run_child_session` 및 `create_child_runner` 함수 구현:
   - 함수 내부에서 `HermesAgent`, `build_child_system_message`, `create_child_dispatcher`를 지연 import하여 모듈 최상위 순환 참조를 방지한다.
   - `child_session_id = str(uuid.uuid4())`를 사전 발급하여 `HermesAgent(session_id=child_session_id, ...)`에 전달한다.
   - 에이전트 생성 및 `run_conversation` 실행 전체를 `try ... except Exception as e:`로 감싸 예외 발생 시 `caught_exception = e`에 포획한다.
   - 반환 딕셔너리 형태:
     ```python
     {
         "child_session_id": child_session_id,
         "run_result": run_result,
         "caught_exception": caught_exception,
     }
     ```
   - `create_child_runner() -> ChildRunnerPort`는 `run_child_session`을 반환한다.

```python
def run_child_session(
    goal: str,
    context: Optional[str] = None,
    *,
    session_db: Any,
    parent_session_id: str,
    llm_client: Any,
    max_iterations: int = DELEGATE_CHILD_MAX_ITERATIONS,
    dispatcher: Optional[Any] = None,
) -> dict[str, Any]:
    """격리된 자식 에이전트 세션을 생성하고 1회 대화를 실행한다 (D-04, R-2)."""
    from hermes_core.agent.agent import HermesAgent
    from hermes_core.agent.prompt_builder import build_child_system_message
    from hermes_core.tools.dispatcher import create_child_dispatcher

    child_session_id = str(uuid.uuid4())
    caught_exception: Optional[Exception] = None
    run_result: Optional[dict[str, Any]] = None

    try:
        child_agent = HermesAgent(
            session_id=child_session_id,
            session_db=session_db,
            dispatcher=dispatcher if dispatcher is not None else create_child_dispatcher(),
            llm_client=llm_client,
            max_iterations=max_iterations,
            quiet_mode=True,
            system_message=build_child_system_message(context),
            parent_session_id=parent_session_id,
            source=SUBAGENT_SOURCE,
            skip_memory=True,
            skip_context_files=True,
        )
        child_session_id = child_agent.session_id
        run_result = child_agent.run_conversation(goal)
    except Exception as e:
        caught_exception = e

    return {
        "child_session_id": child_session_id,
        "run_result": run_result,
        "caught_exception": caught_exception,
    }


def create_child_runner() -> ChildRunnerPort:
    """기본 자식 실행기(run_child_session)를 반환한다."""
    return run_child_session
```

3. `delegate_task` 내부 실행 흐름 개선:
   - 실행기 결정: `runner: ChildRunnerPort = child_runner if child_runner is not None else run_child_session`
   - 디스패처 생성: `child_dispatcher = create_child_dispatcher()`를 직접 호출하여 넘김 (`dt_module.create_child_dispatcher` 패치 호환 보존).
   - `child_session_id: Optional[str] = None` 및 `end_reason = "exception"`을 선언하고 `try ... finally` 블록 구성:
     ```python
     child_session_id: Optional[str] = None
     end_reason = "exception"
     try:
         outcome = runner(
             goal,
             context,
             session_db=session_db,
             parent_session_id=parent_session_id,
             llm_client=child_client,
             max_iterations=max_iterations,
             dispatcher=child_dispatcher,
         )
         child_session_id = outcome.get("child_session_id")
         run_result = outcome.get("run_result")
         caught_exception = outcome.get("caught_exception")

         # 기존 5단계 판정 로직 (caught_exception, stopped_reason, final_response 분석)
         if caught_exception is not None:
             stopped_reason = "exception"
             final_response = ""
             iterations = 0
             error_payload = {
                 "kind": "exception",
                 "message": str(caught_exception),
             }
         else:
             final_response = (run_result.get("final_response", "") or "") if run_result else ""
             iterations = run_result.get("iterations", 0) if run_result else 0
             stopped_reason = run_result.get("stopped_reason", "completed") if run_result else "completed"
             error_payload = run_result.get("error") if run_result else None

         if stopped_reason == "completed":
             if not final_response.strip():
                 status = "failed"
                 end_reason = "empty_response"
                 error_payload = {
                     "kind": "empty_response",
                     "message": "Subagent returned an empty response.",
                 }
             else:
                 status = "completed"
                 end_reason = "completed"
         else:
             status = "failed"
             end_reason = stopped_reason
             if error_payload is None:
                 error_payload = {
                     "kind": stopped_reason,
                     "message": f"Subagent stopped with reason '{stopped_reason}'.",
                 }
     finally:
         # 자식 세션 마감 보장: 세션 ID가 확정되었다면 어떤 예외가 발생해도 end_session 호출 (R-2)
         if child_session_id is not None:
             try:
                 session_db.end_session(child_session_id, end_reason=end_reason)
             except Exception:
                 pass
     ```
   - 7단계(요약 절삭), 8단계(토큰 집계), 9단계(결과 JSON 반환)는 기존 로직을 그대로 유지한다.
