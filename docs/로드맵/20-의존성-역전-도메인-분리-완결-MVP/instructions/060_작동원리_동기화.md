   - 저장소 프로토콜(`DelegateStorePort`) 및 조립 분리(`assembly.run_child_session`).
3. **2부 Q11 (체크포인트와 되돌리기)**:
   - **체크포인트 순수 도메인 분리 (R-4)**:
     - 디스크 파일 쓰기·원장 I/O와 순수 롤백 판정 로직을 엄격히 격리.
     - 충돌 판정(`evaluate_rollback_row`), 중단 턴 분류(`classify_interrupted_rows`), 알림 문구 렌더링(`format_rollback_notice`, `format_interrupt_notice`, `format_pending_notices`)을 `tools/checkpoint_domain.py`로 분리하여 파일시스템이나 DB 없이 독립적으로 완전 검증 가능하게 함.
     - `tools/checkpoint.py`는 도메인 로직을 위임받고 파일시스템·장부 I/O 조율에만 집중하며, 기존 `from hermes_core.tools.checkpoint import ...` 재수출 호환성을 100% 보존.
   - **장부 캡슐화 (`CheckpointStorePort`)**:
     - `checkpoint.py`의 `self.db._conn.execute(...)` 직접 침범 3곳을 `session_db.py`의 공개 메서드 `count_child_sessions`로 캡슐화하여 비공개 커넥션 누수를 차단.
4. **2부 Q12 (취소와 중단, 정합성 보호)**:

     - 취소 복구 블록에서 `history = agent.load_conversation_history()`를 명시적으로 재호출하여 인메모리 `history`를 장부 원장의 최신 `active=1` 상태(보존된 요약본 포함)와 완벽히 재동기화함으로써 메모리와 원장의 불일치(Split-Brain)를 차단.
   - **턴 시작 경계 Fail-Safe 보호 (R-3)**:
     - REPL 루프 시작 경계에서 `panel.apply_pending()`이나 `get_last_active_message_id`가 감사 장부 에러 등으로 예외를 던지더라도 세션이 강제 종료되지 않고 경고 로그 후 안전하게 턴 대화를 진행.
5. **5부 ② 코드 정본 색인 갱신**:
