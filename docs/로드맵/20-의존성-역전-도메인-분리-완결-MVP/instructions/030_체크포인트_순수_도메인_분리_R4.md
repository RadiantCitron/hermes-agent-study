3. 순수 도메인 판정 함수 2종 구현:
   - `evaluate_rollback_row(row: Mapping[str, Any], *, resolved_workspace_str: str, path_check_error: Optional[str], current_file_state: Optional[tuple[bool, Optional[str]]], simulated_file_state: dict[str, tuple[bool, Optional[str]]]) -> tuple[RollbackItem, bool]`:
     - `row` 필드 추출: `cid = row["id"]`, `tool_name = row["tool_name"]`, `ws = row["workspace"]`, `rel_path = row["rel_path"]`, `before_exists = bool(row["before_exists"])`, `before_content = row["before_content"]`, `after_sha256 = row["after_sha256"]`, `status = row["status"]`.
     - `will_skip = False`, `skip_reason: Optional[str] = None`, `is_pending_warning = False` 초기화.
     - 판정 순서:
       1. 작업 폴더 불일치: `ws != resolved_workspace_str`이면 `will_skip = True`, `skip_reason = "작업 폴더 불일치"`.
       2. 경로 재판정 실패: `path_check_error is not None`이면 `will_skip = True`, `skip_reason = f"경로 재판정 실패 ({path_check_error})"`.
       3. pending 상태: `status == CHECKPOINT_STATUS_PENDING`이면 `will_skip = True`, `skip_reason = "결과 모름(pending)"`, `is_pending_warning = True`.
       4. applied 상태:
          - `rel_path not in simulated_file_state`인 경우:
            - `current_file_state is not None`이면 `simulated_file_state[rel_path] = current_file_state`.
            - `current_file_state is None`이면 `simulated_file_state[rel_path] = (False, None)`.
          - `file_exists, file_sha = simulated_file_state[rel_path]`
          - `not file_exists`: `will_skip = True`, `skip_reason = "충돌(파일 부재)"`.
          - `file_sha != after_sha256`: `will_skip = True`, `skip_reason = "충돌(외부 변경)"`.
          - 정상 일치: `will_skip = False`, `skip_reason = None`.
            - 가상 복원 상태 갱신: `if before_exists:` `b_bytes = before_content.encode("utf-8") if before_content is not None else b""`, `simulated_file_state[rel_path] = (True, hashlib.sha256(b_bytes).hexdigest())`. `else:` `simulated_file_state[rel_path] = (False, None)`.
     - `item = RollbackItem(...)` 생성 후 `(item, is_pending_warning)` 반환.
   - `classify_interrupted_rows(turn_index: int, rows: Sequence[Mapping[str, Any]]) -> Optional[InterruptedTurn]`:
     - `target_statuses = (CHECKPOINT_STATUS_APPLIED, CHECKPOINT_STATUS_PENDING, CHECKPOINT_STATUS_FAILED)`
     - `items = [InterruptedItem(rel_path=r["rel_path"], status=r["status"]) for r in rows if r.get("status") in target_statuses]`
     - `if not items: return None`
     - `return InterruptedTurn(turn_index=turn_index, items=tuple(items))`

4. 순수 알림 렌더러 함수 4종 구현:
   - `_escape_control(s: str) -> str`: 제어문자 repr 치환.
   - `format_rollback_notice(results: Sequence[RollbackResult]) -> Optional[str]`: 롤백 알림 텍스트 조립.
   - `format_interrupt_notice(turn: InterruptedTurn) -> Optional[str]`: 인터럽트 알림 텍스트 조립.
   - `format_pending_notices(items: Sequence[Union[RollbackResult, InterruptedTurn]]) -> Optional[str]`: 보류 알림 병합.

## 2. 인수 테스트 시나리오 (8개)

### 시나리오 1: `evaluate_rollback_row` 단일 행 판정 6대 분기 검증 (순수 함수)
- **입력**:
  1. `ws != "/ws"`인 row -> 작업 폴더 불일치
  2. `path_check_error="상위 탈출 금지"`인 row -> 경로 재판정 실패
  3. `status="pending"`인 row -> pending 경고 및 `is_pending_warning is True`
  4. `status="applied"`, `current_file_state=(False, None)`인 row -> 충돌(파일 부재)
  5. `status="applied"`, `current_file_state=(True, "different_sha")`인 row -> 충돌(외부 변경)
  6. `status="applied"`, `current_file_state=(True, "exact_sha")`, `before_exists=True`인 row -> 정상 복원 가능
- **기대 결과**:
  - 각 분기별로 `will_skip` 불리언과 `skip_reason` 문자열이 기존 `checkpoint.py`와 100% 동일하게 생성된다.
  - 분기 3에서 반환 튜플의 두 번째 원소(`is_pending_warning`)가 `True`이다.

### 시나리오 2: `evaluate_rollback_row` 동일 파일 다중 수정 시 역순 가상 복원 상태 추적 검증
- **입력**: 동일 파일 `doc.txt`에 대해 최신 수정(row 2: `before="v1"`, `after="v2"`)과 과거 수정(row 1: `before="v0"`, `after="v1"`)을 역순으로 `evaluate_rollback_row`에 연속 전달. 초기 디스크 상태 `current_file_state=(True, sha("v2"))`, 빈 `simulated_file_state = {}`.
- **기대 결과**:
  - row 2 평가 후 `item.will_skip is False`이고, `simulated_file_state["doc.txt"]`가 `(True, sha("v1"))`로 전이된다.
  - row 1 평가 시 `current_file_state`를 다시 전달하지 않아도 `simulated_file_state`의 가상 상태 `sha("v1")`와 row 1의 `after_sha256`이 일치하여 `item.will_skip is False`로 판정되고 `simulated_file_state["doc.txt"]`가 `(True, sha("v0"))`로 전이된다.

### 시나리오 3: `classify_interrupted_rows` 상태 필터링 및 조립 검증
- **입력**:
  - 케이스 A: `applied`, `pending`, `failed`, `skipped`, `rolled_back` 행이 섞인 `rows` 리스트
  - 케이스 B: `skipped`, `rolled_back` 행만 있는 `rows` 리스트
  - 케이스 C: 빈 리스트 `rows = []`
- **기대 결과**:

  - 케이스 B: `None` 반환.
  - 케이스 C: `None` 반환.

### 시나리오 4: 알림 포맷 순수 함수 검증 (`format_rollback_notice`, `format_interrupt_notice`, `format_pending_notices`)
