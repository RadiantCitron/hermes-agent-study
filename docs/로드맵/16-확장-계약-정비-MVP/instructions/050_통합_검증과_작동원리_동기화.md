## 1. 구현 내용 명세

이 단계는 **소스코드를 한 줄도 바꾸지 않는다.** 계약이 실제 클라이언트 경로와 위임 중첩 실행에서도 지켜지는지 시험으로 확인하고, 바뀐 구조를 문서에 반영한다.

### 1-1. 통합 시험 (`tests/test_hermes_core/test_extension_e2e.py`, 신규)

시험 파일 안에서만 쓰는 가짜 확장 둘:
- `CountingGuard`(GUARD 단계): 턴 칸에 도구 호출 횟수를 쌓는다. 설정에 따라 일부 호출에서 `next` 전에 예외를 던질 수 있다.
- `DenyPolicy`(POLICY 단계): 지정한 도구 이름이면 `next`를 부르지 않고 `{"success": false, "error": "denied"}`를 반환한다.

### 1-2. 문서 동기화

[작동원리 README](../../../작동원리/README.md)의 규칙(쉬운 말, Why, 구현 귀띔, 이름의 3층)을 따른다.
- [03-코어구조-메인루프-확장방식.md](../../../작동원리/03-코어구조-메인루프-확장방식.md): 기준 커밋·「다시 확인하는 법」, 확장 계약(상태 칸, 무엇을 볼 수 있고 바꿀 수 있나, 대화 변경 연산, 단계별 순서·고장 규칙, 확장 설치와 목록), 그림, 5부 ②·③.
- [코딩규약.md](../../../코딩규약.md): §1 대조표에 `extensions/contract.py` 행 추가, `agent/compression_hook.py` 행을 `CompressionExtension`으로. §3-7을 ADR-0016 계약으로 개정 — 「원장 일치는 해당 훅의 책임」 문장을 지우고 「대화 변경은 `replace_transcript`만」, 「상태는 확장 이름별 턴·세션 칸에만」, 「미들웨어는 단계로 등록, 실패 정책은 단계가 정함」, 「전역·`ContextVar` 금지」, 「`TurnContext`의 코어 전용 필드(`_live_messages`, `_replace_fn`)는 확장이 쓰지 않음」을 넣는다.
- [ROADMAP.md](../ROADMAP.md): 구현 결과에 맞춰 그림 정정.
- 사실 검증 4축(동작·순서·소유자·시점)으로 실제 코드와 대조하고, 확인하지 못한 것은 「미확인」.

## 3. 인수 테스트 시나리오 (구현 전 작성, 임의 변경 금지)

| # | 입력 | 기대 결과 |
|---|---|---|
| E1 | 실제 `OpenRouterClient`+`MockTransport`(기존 `test_agent_e2e.py` 구성 참고), 작은 `context_window_tokens`로 압축이 1회 일어나는 대화 + `CountingGuard`·`DenyPolicy` 설치 | `result["compression"]["count"] >= 1`, 거부 도구의 `tool` 메시지는 `denied`, 나머지는 정상. `get_messages_as_conversation(session_id)`가 메모리 `messages[1:]`와 같다 (가정 A·C) |
| E2 | E1에서 `CountingGuard`가 모든 호출에서 `next` 전 예외 | 도구는 각각 1회 실행, 턴이 `completed`로 끝남, `extension_error` 이벤트가 호출 수만큼, `agent.extensions`의 실패 횟수가 같음 (가정 E) |
| E3 | 부모 디스패처에 `CountingGuard`를 달고 `register_delegate_tool`로 위임 도구 등록. 시험이 `hermes_core.tools.delegate_tool.create_child_dispatcher`를 monkeypatch해 자식 디스패처에도 `CountingGuard`를 단다(`src/` 무수정). 부모가 도구 1회 + 위임 1회, 자식이 도구 2회 호출 | 부모 턴 칸의 횟수는 부모 호출만(2), 자식 턴 칸의 횟수는 자식 호출만(2) 센다. 부모 미들웨어가 받은 `call.scope`는 모두 부모 턴의 같은 객체, 자식 쪽은 자식 턴의 객체로 서로 다르다 (가정 H) |
| E4 | E1 세션을 `HermesAgent(resume=True)`로 다시 열고 한 턴 더 | `agent.extensions[0].name == "compression"`, 재개 뒤 원장과 메모리 일치 |
| E5 | 확장 하나도 추가 설치하지 않은 대조 에이전트로 E1과 같은 입력(거부 대상 없음) | 이 로드맵 전과 같은 결과 형식, `hook_error`·`extension_error` 0건 |
