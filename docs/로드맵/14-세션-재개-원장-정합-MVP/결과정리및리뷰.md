## 1. 목표와 결과 요약

### 1-1. 목표
1. **취소 턴 원장 정합 (가정 A, B)**: 처리 중 `Ctrl+C` 취소 시 메모리 `history`에서 제외된 미완성 메시지들을 DB 원장(`messages` 테이블)에서도 삭제 없이 `active=0`으로 내려, 원장의 `active=1` 대화와 메모리 대화의 100% 일치를 달성한다.
2. **세션 재개 (`--resume`) (가정 C, D, E, F)**: 프로그램을 껐다가 다시 켤 때 기존 CLI 세션을 이어받아(`reopen_session`), 처음 세션의 시스템 프롬프트 스냅샷(Prompt Cache 보존)과 활성 대화 이력을 복원하고, 체크포인터 상태를 복원하여 **지난 세션의 파일 변경분에 대한 `/rollback`**과 **턴 번호의 단조 증가**를 지원한다.

### 1-2. 결과
- **전체 목표 100% 달성**:
  - `SessionDB`에 4종 계약(`get_last_active_message_id`, `deactivate_messages_after`, `reopen_session`, `find_resumable_session`) 구현 및 검증.
  - `Checkpointer.restore_from_db`로 12번 한계 1(이전 세션 롤백 불가) 완전 해소.
  - `HermesAgent(resume=True)` 및 `load_conversation_history()`로 프롬프트 캐시 스냅샷 불변 보존 및 대화 연속성 보장.
  - `cli.py`에 `--resume [latest|<prefix>]` 옵션 배선 및 취소 시 `deactivate_messages_after` 결합.
  - 총 35개의 신규 단위/통합/E2E 테스트 시나리오 작성 및 전체 회귀 테스트(855 passed, 10 pty passed) 무결함 통과.

## 4. 미흡한 부분 및 알려진 한계

1. **대화 중간 지점 분기(Branching) 미지원**:
   - 세션 재개는 가장 최근 턴 끝에서 이어 달리기만 지원하며, 특정 과거 턴으로 롤백한 뒤 새 가지로 분기하는 git식 브랜칭은 지원하지 않음.
2. **대화형 TUI 선택창 부재**:
   - `--resume` 시 대상 세션이 여러 개이거나 목록을 보고 고르고 싶을 때 TUI 선택창이 없으며, 인자가 없으면 `latest`, 모호한 접두사면 에러로 종료됨.
3. **위임 자식(서브에이전트) 세션 단독 재개 불가**:
   - `source = 'cli' AND parent_session_id IS NULL`인 세션만 재개 대상이며, 위임 자식 세션은 부모 맥락 없이 단독 재개할 수 없음(설계상 의도된 제약).
4. **미전송 보류 알림 세션 간 미승계**:
   - 세션이 종료되기 직전 모델에게 전달되지 못한 롤백/취소 알림은 다음 세션으로 승계되지 않고, 종료 시 화면 주의 안내로 갈음됨.

## 5. 새로 발견한 사실 (인사이트)

1. **Prompt Caching 보존을 위한 스냅샷 동결의 결정적 중요성**:
   - 세션을 재개할 때 메모리 파일(`MEMORY.md`)이나 스킬 목록을 다시 읽어 시스템 지시문을 재조립하면, 글자가 미세하게 달라져 프롬프트 캐시가 깨짐. 첫 세션 생성 시 DB에 저장된 `system_prompt` 스냅샷을 그대로 재사용함으로써 캐시 적중률과 비용 효율을 보장할 수 있음을 실증함.
2. **압축 후 취소 경계 방어(`effective_after_id`)의 필연성**:
   - 한 턴 처리 도중 컨텍스트 압축이 발동되고 이어서 모델 호출/도구 실행 중 `Ctrl+C`가 발생했을 때, 단순 `after_id`로 비활성화하면 압축 요약 행과 꼬리 복사본까지 비활성화되어 대화가 파괴됨. 압축 행들의 최대 ID를 고려한 `effective_after_id` 방어가 데이터 무결성에 필수적임을 증명함.

## 6. 후속 과제 후보

1. **세션 히스토리 조회 및 대화형 선택 CLI**: 과거 세션 목록(시작 시각, 메시지 수, 마지막 질의)을 보여주고 번호로 선택해 재개하는 대화형 TUI.
2. **세션 브랜칭(분기 재개)**: 특정 과거 턴 시점으로 되돌린 뒤 부모 세션 ID를 연결하여 새로운 자식 가지 세션을 생성하는 분기 메커니즘.
