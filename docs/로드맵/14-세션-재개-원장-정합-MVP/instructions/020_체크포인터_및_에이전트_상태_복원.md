## 1. 구현 내용 명세

010에서 만든 DB 계약 위에서, 세션을 다시 열었을 때 ① [`Checkpointer`](../../../../src/hermes_core/tools/checkpoint.py)가 이전 턴 번호·누적 바이트 예산·턴 시작 시각을 복원하여 새 턴 번호 충돌을 막고 이전 세션 변경분의 `/rollback`을 가능하게 하며, ② [`HermesAgent`](../../../../src/hermes_core/agent/agent.py)가 기존 세션을 다시 열고(`reopen_session`) 시스템 프롬프트 스냅샷과 활성 대화 이력을 복원하게 만든다.

### 1-1. 체크포인터 상태 복원 (`Checkpointer.restore_from_db`) ([`checkpoint.py`](../../../../src/hermes_core/tools/checkpoint.py))

`Checkpointer.begin_turn` 바로 위에 메서드를 추가한다.

```python
def restore_from_db(self) -> int:
    """DB의 file_checkpoints 원장에서 기존 세션의 마지막 turn_index, 누적 바이트, 턴별 시작 시각을 복원하고 복원된 turn_index를 반환한다."""
```

- `rows = self.db.get_file_checkpoints(self.session_id)`를 조회한다.
- `rows`가 비어 있으면:
  - `self.turn_index = 0`
  - `self.turn_started_at = 0.0`
  - `self._turn_start_times = {}`
  - `self._session_before_bytes = 0`
  - `return 0`
- `rows`가 1건 이상이면:
  - `self.turn_index = max(r["turn_index"] for r in rows)`
  - `self._session_before_bytes = sum(len(r["before_content"].encode("utf-8")) for r in rows if r["before_exists"] and isinstance(r["before_content"], str))`
  - `turn_times: dict[int, float] = {}`를 만들어 각 행의 `t = r["turn_index"]`, `c = float(r["created_at"] or 0.0)`에 대해 `turn_times[t] = min(turn_times[t], c) if t in turn_times else c`로 채운다.
  - `self._turn_start_times = turn_times`
  - `self.turn_started_at = self._turn_start_times.get(self.turn_index, 0.0)`
  - `return self.turn_index`

이렇게 복원하면:
1. 재개 직후 새 턴을 시작하기 전에 `/rollback`을 치면 `plan_rollback()`이 이전 세션의 최신 `applied`/`pending` 턴을 그대로 찾고, `_turn_start_times`로 그 턴의 터미널 승인·서브에이전트 경고 여부까지 정확히 계산한다(가정 D, 12번 한계 1 해소).
2. 재개 후 새 턴이 시작되면 `begin_turn()`이 `self.turn_index += 1`을 하므로 이전 세션의 마지막 턴 번호 다음 번호부터 이어져 옛 체크포인트와 절대 섞이지 않는다(가정 E).
3. 이전 세션에서 쓴 체크포인트 용량이 `_session_before_bytes`에 합산되어 세션당 누적 바이트 상한(`self.bytes_limit`)이 세션 전체에 걸쳐 일관되게 지켜진다.

### 1-2. 에이전트 세션 재개 (`HermesAgent(..., resume=False)`) ([`agent.py`](../../../../src/hermes_core/agent/agent.py))

1. `HermesAgent.__init__` 인자 목록 맨 끝(`skills_index: bool = False` 뒤)에 `resume: bool = False`를 추가하고 `self.resume = resume`으로 저장한다.
2. 기존 세션 DB 레코드 생성 및 `_cached_system_prompt` 초기화 부분(`agent.py:192-203`)을 아래와 같이 분기한다.
   ```python
   if self.resume:
       existing = self.session_db.get_session(self.session_id)
       if existing is None:
           raise ValueError(f"Cannot resume session '{self.session_id}': session does not exist.")
       self.session_db.reopen_session(self.session_id)
       saved_prompt = existing.get("system_prompt")
       self._cached_system_prompt = (
           saved_prompt if isinstance(saved_prompt, str) and saved_prompt else None
       )
   else:
       self.session_db.create_session(
           session_id=self.session_id,
           source=self.source,
           model=self.model,
           mode=self.mode,
           system_prompt=None,
           parent_session_id=self.parent_session_id,
       )
       self._cached_system_prompt = None
   ```
   - `saved_prompt`가 이미 있으면 `_cached_system_prompt`에 들어가므로, 이후 `_build_system_prompt()`가 호출될 때 재조립이나 `update_system_prompt` 덮어쓰기 없이 첫 세션의 시스템 프롬프트 스냅샷을 그대로 반환한다(Prompt Cache 보존, 가정 C).
   - 첫 세션에서 한 마디도 안 하고 종료해 `system_prompt`가 `None`이었던 경우에만 `_cached_system_prompt`가 `None`이 되어 첫 턴에 새로 조립·저장된다(위험 5).

### 1-3. 활성 대화 이력 복원 (`HermesAgent.load_conversation_history`) ([`agent.py`](../../../../src/hermes_core/agent/agent.py))

`_build_system_prompt` 바로 아래에 메서드를 추가한다.

```python
def load_conversation_history(self) -> Optional[list[dict[str, Any]]]:
    """원장의 활성(active=1) 메시지를 읽어 run_conversation에 넘길 conversation_history 목록([system, ...])으로 반환한다. 활성 메시지가 없으면 None."""
    active_msgs = self.session_db.get_messages_as_conversation(self.session_id)
    if not active_msgs:
        return None
    sys_prompt = self._build_system_prompt()
    return [{"role": "system", "content": sys_prompt}, *active_msgs]
```

- 활성 메시지가 0건이면 `None`을 반환한다(`_build_system_prompt`도 부르지 않아 빈 세션 재개 시 프롬프트 조립을 실제 첫 발화 시점까지 지연).
- 활성 메시지가 1건 이상이면 맨 앞에 `{"role": "system", "content": sys_prompt}`를 붙인 리스트를 반환하므로, CLI의 `history` 변수에 그대로 넣어 다음 `agent.run_conversation(user_input, conversation_history=history)`에 넘길 수 있다.
