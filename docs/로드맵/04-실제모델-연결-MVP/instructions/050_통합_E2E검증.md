## 1. 구현 내용 명세

실제 클라이언트(`OpenRouterClient`)에 **정해진 순서로 응답하는 `httpx.MockTransport`**를 꽂아, 기본 도구 6종 디스패처·실제 `SessionDB`·작업 폴더 `W = <HERMES_HOME>/workspace`(현재 폴더로 이동)로 에이전트를 돌린다. 시험 파일은 `tests/test_hermes_core/test_agent_e2e.py`에 **추가**한다(기존 시험은 그대로).

가짜 제공자의 응답은 실제 제공자 형식(`choices[0].message`, `usage`)을 흉내 낸다. 가정 C(실제 모델의 인자 형식)는 이 시험으로 검증되지 않는다(060 담당).

## 4. 검증 기준 (Done 조건)

1. 시나리오 1~14가 통과한다.
2. 키·비밀 값이 어떤 저장 위치에도 없음을 확인했다 (시나리오 4·5·6).
3. `git diff <단계 시작 커밋>..HEAD -- src/`가 비어 있다. 기존 시험은 삭제된 줄이 없다.
4. 실패한 시나리오가 있으면 임의로 `src/`를 고치지 않고 멈춰서 원인과 함께 보고한다.
