# [구현지시서 060] 실제 키 스모크 1회 (사용자 지시가 있을 때만 실행)

> **상위 대시보드**: [04-README.md](../README.md)  
> **선행 조건**: 050 단계 완료 (`Done`) **그리고 사용자의 명시적 실행 지시**  
> **근거**: [WHY.md](../WHY.md) 가정 C·E, [ADR-0004](../../../adr/0004-실제_모델_연결_MVP_범위와_안전_정책.md) §2-2  
> **성격**: 코드를 바꾸지 않는 **실행·검증 단계**다. 지시서는 절차와 기대 결과만 정한다. 실행 결과는 대시보드와 종합보고서에 기록한다.

---

## 1. 목적

가짜 전송으로 모든 시험이 통과한 상태에서, **실제 모델로 도구를 한 번 쓰고 돌아오는 한 번의 대화**가 성공하는지, 그 기록이 남는지, 그 과정에서 키가 어디에도 남지 않는지를 확인한다. 가정 C(실제 모델이 보내는 도구 호출 형식)는 이 단계에서만 검증할 수 있다.

## 2. 사전 조건 (사용자가 확인)

1. 키 변수 이름은 `OPENROUTER_API_KEY`로 사용자가 확인했다(2026-10-28). 사용자의 셸에서 이 이름으로 내보냈는지만 확인한다. 에이전트는 `.env`를 열지 않는다.
2. **별도 터미널**(에이전트 세션이 아닌 사용자의 터미널)에서 직접 환경변수로 키를 내보낸다(`export OPENROUTER_API_KEY=...` 또는 `set -a; source .env; set +a`). **키는 에이전트와의 대화·명령줄·프롬프트에 절대 쓰지 않는다** (도구 호출 기록과 대화록에 남고, 대화록 검사는 문장 속 키를 잡지 못한다. [AGENTS.md](../../../../AGENTS.md) §3).
3. `pytest tests -q`가 모두 통과한다.
4. 비용 상한: 호출은 최대 반복 50회로 제한되지만 이 스모크는 **한 번의 대화(2~3회 호출)**만 한다. 출력 토큰 상한이 4,096이므로 호출당 최대 약 $0.001 수준이다(공개 단가 기준, 실제 청구는 확인하지 못함).

## 3. 절차

| 순서 | 동작 |
|---|---|
| 1 | **사용자가 별도 터미널에서 직접** 레포 루트에서 `python -m hermes_core.cli` 실행 (`--mock` 없음). 에이전트는 이 실행을 대신하지 않는다 |
| 2 | 시작 안내에서 모드(실제), 모델(`deepseek/deepseek-v4-flash-0731`), 작업 폴더(`.hermes/workspace`)를 확인 |
| 3 | 입력: `workspace에 hello.txt를 만들고 내용에 hi라고 써줘. 그다음 그 파일을 읽어서 내용을 알려줘.` |
| 4 | 응답을 확인하고 `exit` |
| 5 | 실행 결과 확인(아래 4절). 사용자가 비밀을 뺀 출력과 확인 결과를 에이전트에게 전달하고, 에이전트는 원장 조회(읽기 전용)와 기록 정리를 한다 |

실패(오류 종료, 이상한 응답)하면 **자동으로 다시 시도하거나 코드를 고치지 않는다.** 원인을 기록하고 멈춰서 보고한다. 같은 스모크를 다시 하려면 사용자의 새 지시가 필요하다.

## 4. 기대 결과와 확인 항목

| # | 확인 | 기대 결과 |
|---|---|---|
| 1 | 작업 폴더 | `.hermes/workspace/hello.txt`가 있고 내용이 `hi` |
| 2 | 응답 | 모델이 도구로 만든 파일을 읽어 내용을 알려 줌. `Model call failed`가 출력되지 않음 |
| 3 | 원장: `sessions` | 해당 세션의 `model == "deepseek/deepseek-v4-flash-0731"`, `mode == "real"`, 토큰 합계가 0보다 큼 |
| 4 | 원장: `llm_calls` | 호출 수만큼 행이 있고 `error_kind`가 모두 NULL, `request_json`·`response_json`이 있음 |
| 5 | **가정 C**: 응답의 도구 호출 | `tool_calls`의 `arguments`가 문자열로 와서 도구가 정상 실행되었다. 다른 모양(객체 등)이면 기록하고 보고 |
| 6 | **키 미저장** | 키가 원장 덤프(`sqlite3 .hermes/state.db .dump`)에 없다. **사용자가 별도 터미널에서** 키 값을 출력하지 않고 확인하고 결과(`True`/`False`)만 전달한다 (예: `python3 -c "import os,sys; k=os.environ['OPENROUTER_API_KEY']; d=sys.stdin.read(); print(k in d)"`로 `False`) |
| 7 | **비밀 파일 미접근** | 대화 어디에도 `.env` 내용이 나타나지 않는다 |
| 8 | 비용 (**가정 E**) | OpenRouter 사용량 화면 또는 `llm_calls`의 토큰으로 계산한 비용이 1센트 미만 |
| 9 | 출력·로그 | 키 값이 화면·로그에 없다 |

## 5. 결과 기록

- 대시보드 실행 기록에 날짜, 지시 문구, 통과/실패, 호출 수, 토큰, 계산한 비용을 적는다.
- 위 확인 항목 5(가정 C)·8(가정 E)의 관찰을 **그대로** 종합보고서의 「목표와 결과」·「새로 발견한 부분」에 옮긴다. 기대와 다르면 「틀렸다」로 적는다.
