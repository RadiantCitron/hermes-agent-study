## 1. 구현 내용 명세

1. **상수** ([`constants.py`](../../../../src/hermes_core/constants.py)): `CONTEXT_WINDOW_TOKENS = 1_048_576`, `COMPRESSION_THRESHOLD_RATIO = 0.5`, `MESSAGE_TOKEN_OVERHEAD`(메시지당 고정 가산, 후보 4), `COMPRESSION_TAIL_TOKENS = 20_000`(최근 보호 예산의 상한), `COMPRESSION_TAIL_RATIO = 0.25`(임계값 대비 최근 보호 예산 비율), `COMPRESSION_RETRY_GROWTH = 1.25`(압축이 거부된 뒤 재시도하려면 토큰이 이만큼 커져야 함).
2. **신규 모듈** `src/hermes_core/agent/context_budget.py` (순수 함수, 모델·DB·파일 접근 없음):
   - `estimate_tokens_rough(text: str | None) -> int`: `None`/빈 문자열은 0. 한글·한자·가나 등 CJK 글자는 1자=1토큰, 나머지는 `ceil(UTF-8 바이트 수 / 4)`.
   - `estimate_messages_tokens(messages, tools=None) -> int`: 각 메시지 `content` 추정 + `tool_calls`를 JSON 직렬화한 문자열 추정 + `MESSAGE_TOKEN_OVERHEAD`, 그리고 `tools` 스키마(있을 때) 직렬화 추정을 합산.
   - `estimate_current_tokens(messages, tools, last_input_tokens, last_message_count) -> int`: `last_input_tokens`가 `None`이 아니면 `last_input_tokens + estimate_messages_tokens(messages[last_message_count:])`, 아니면 전체 추정치. (`last_message_count`는 그 실제 토큰 수가 보고된 호출 시점의 `messages` 길이.)
   - `compression_threshold(window: int, ratio: float) -> int`: `int(window * ratio)`.
   - `should_compress(tokens: int, threshold: int) -> bool`: `tokens >= threshold`.
   - `compression_tail_budget(threshold: int) -> int`: `min(COMPRESSION_TAIL_TOKENS, int(threshold * COMPRESSION_TAIL_RATIO))`. **창이 작을 때 최근 보호 예산이 임계값보다 커져 중간 구간이 없어지는 것을 막는다**(예: 임계값 2,000이면 500).
   - `may_retry_after_reject(current_tokens: int, rejected_at_tokens: Optional[int]) -> bool`: 거부 기록이 없으면 `True`, 있으면 `current_tokens >= rejected_at_tokens * COMPRESSION_RETRY_GROWTH`. 거부가 반복되며 매 호출마다 요약 호출이 나가는 폭주를 막는 판정이다(연동은 050).
3. **작동원리 갱신**: 없음.
