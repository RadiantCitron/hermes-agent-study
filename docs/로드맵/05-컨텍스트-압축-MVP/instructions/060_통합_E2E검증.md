## 4. 검증 기준 (Done 조건)

1. 시나리오 1~11이 통과한다 (`test_agent_e2e.py`).
2. 전체 테스트(`pytest tests -q`)가 통과한다. `git diff <단계 시작 커밋>..HEAD -- tests/`에서 **삭제된 줄이 0**이다.
3. `git diff <단계 시작 커밋>..HEAD -- src/`가 비어 있다(이 단계는 코드를 바꾸지 않는다).
4. 작동원리 01편 변경분을 사실 검증 4축(동작·순서·소유자·시점)으로 실제 코드와 대조했고, 확인하지 못한 것은 「미확인」으로 표기했다.
