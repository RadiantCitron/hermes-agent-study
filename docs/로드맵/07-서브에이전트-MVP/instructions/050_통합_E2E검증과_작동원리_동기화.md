## 3. 인수 테스트 시나리오 (구현 전 작성, 임의 변경 금지)

## 4. 검증 기준 (Done 조건)

1. 시나리오 1~12가 통과한다 (`test_agent_e2e.py`). 시나리오 13은 작동원리 문서의 코드 대조로 확인한다.
2. 기존 테스트가 모두 통과한다. 테스트 파일 diff에서 **삭제된 줄이 0**이다.
3. `git diff <단계 시작 커밋>..HEAD -- src/`가 비어 있다 (`src/` 무변경).
4. 작동원리 01편의 머리(기준일·기준 커밋)를 [작동원리 README](../../../작동원리/README.md)의 기준 커밋 정의에 따라 갱신한다. 시험을 추가하는 커밋은 자기 자신의 해시를 문서에 쓸 수 없으므로, 이 문제를 05 060(`ab56d6c`)·06 050(`fc2f171`)이 어떻게 처리했는지 착수 시 그 커밋들을 열어 확인하고 같은 방식을 따른다. 선례와 어긋나거나 규칙이 불분명하면 임의로 정하지 않고 멈춰서 보고한다.
