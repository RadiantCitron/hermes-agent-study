## 1. 구현 내용 명세

1. **작업 폴더 도입** ([`terminal_tool.py`](../../../../src/hermes_core/tools/terminal_tool.py) `terminal_tool`):
   - 시그니처에 `workspace: Optional[Path] = None`을 추가한다. `None`이면 호출 시점의 현재 작업 폴더(`Path.cwd()`)를 쓴다.
   - 프로세스는 항상 `cwd=<작업 폴더>`에서 실행한다.
2. **경로 인자 검사**: 첫 토큰을 뺀 각 인자에 대해
   - `-`로 시작하는 옵션 중 `=`가 있으면 `=` 뒤의 값을, `=`가 없으면 옵션 자체는 건너뛴다.
   - 그 밖의 인자는 작업 폴더 기준으로 `resolve()`(심볼릭 링크 해석 포함)한 경로가 작업 폴더 **안**인지 검사한다. 밖이면 실행하지 않고 `{"success": false, "error": "Path '<인자>' is outside the workspace."}`를 반환한다.
   - 존재하지 않는 경로도 같은 방식으로 검사한다 (`resolve(strict=False)`).
3. **알려진 한계** (보수적 판정): 경로가 아닌 인자도 검사 대상이다. 예를 들어 `grep / a.txt`의 패턴 `/`는 작업 폴더 밖으로 풀려 거부된다. 완화는 후속 로드맵의 과제로 둔다.
4. **기존 제한과 040의 가드는 유지한다.**
5. **01편 갱신**: Q3, 3부 방어선 7(격리가 저장 위치에만 해당한다는 문장), 「지금은 없는 방어선」, 5부 ① 터미널·로컬 실행 행, ③ 행을 고친다. `기준 커밋`은 건드리지 않는다.

## 3. 인수 테스트 시나리오 (구현 전 작성, 임의 변경 금지)

임시 폴더 `W`를 작업 폴더로 지정한다. `W`에 `a.txt`(내용 `hello`), `sub/b.txt`를 만들고, `W` 밖에 `outside.txt`를 만든다. `W/link`는 `outside.txt`를 가리키는 심볼릭 링크다.

| # | 입력 (`terminal_tool(command, workspace=W)`) | 기대 결과 |
|---|---|---|
| 1 | `cat a.txt` | `success` true, `stdout`에 `hello` |
| 2 | `cat sub/b.txt` | `success` true |
| 3 | `cat sub/../a.txt` | `success` true (풀면 폴더 안) |
| 4 | `cat /etc/hosts` | `success` false, 오류에 `outside` 포함 |
| 5 | `cat ../outside.txt` | `success` false, 오류에 `outside` 포함. `outside.txt` 내용이 `stdout`에 없음 |
| 6 | `cat link` (폴더 안 링크가 폴더 밖 파일을 가리킴) | `success` false, 오류에 `outside` 포함 |
| 7 | `grep -r root /etc` | `success` false |
| 8 | `grep hello a.txt` | `success` true |
| 9 | `grep --file=/etc/passwd x a.txt` | `success` false (옵션 값의 경로도 검사) |
| 10 | `ls -la` | `success` true (옵션만 있는 경우) |
| 11 | `ls` | `stdout`에 `a.txt` 포함 (`W`에서 실행됨) |
| 12 | `pwd` | `stdout`이 `W.resolve()`(심볼릭 링크를 푼 실제 경로) + 줄바꿈 |
| 13 | `ls ~` | 홈 확장 없음. `~`는 `W` 안의 이름으로 취급되어 `ls`가 파일 없음으로 `success` false이며 홈 폴더 내용이 `stdout`에 없음 |
| 14 | `grep / a.txt` | `success` false, 오류에 `outside` 포함 (알려진 한계를 시험으로 고정) |
| 15 | `workspace` 인자를 주지 않고 현재 작업 폴더를 `W`로 바꾼 뒤 `cat a.txt` | `success` true |
