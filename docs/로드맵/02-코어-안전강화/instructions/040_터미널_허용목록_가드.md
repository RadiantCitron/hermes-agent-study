## 1. 구현 내용 명세

1. **셸 없이 실행** ([`terminal_tool.py`](../../../../src/hermes_core/tools/terminal_tool.py) `terminal_tool`):
   - 명령 문자열을 `shlex.split`으로 인자 목록으로 나누고 `subprocess.run(args_list, shell=False)`로 실행한다. 파이프, `;`, `$()`, `$HOME`, `>` 등은 해석되지 않고 **글자 그대로 인자**로 전달된다.
   - 표준 입력은 닫는다 (`stdin=subprocess.DEVNULL`). 인자 없는 `cat` 등이 입력을 기다리며 멈추지 않게 한다.
2. **허용목록**:
   - 상수 `ALLOWED_COMMANDS = ("echo", "pwd", "ls", "cat", "head", "tail", "wc", "grep")` 하나로 모은다 ([ROADMAP.md §6-1](../ROADMAP.md)).
   - 첫 토큰이 허용목록의 이름과 **정확히 같을 때만** 실행한다. `/bin/ls`처럼 경로가 붙은 이름은 거부한다.
   - 거부하면 실행하지 않고 `{"success": false, "error": "Command '<이름>' is not allowed. Allowed: ..."}`를 반환한다.
3. **파싱 실패 처리**: 따옴표가 닫히지 않는 등 `shlex.split`이 실패하면 예외 없이 `{"success": false, "error": "Cannot parse command: ..."}`를 반환한다.
4. **유지하는 것**: 빈 명령 오류 문구, 반환 형식(`success`, `exit_code`, `stdout`, `stderr`, `error`), 시간 제한 기본 30초, 출력 10,000자 절단과 안내 문구.
5. **스키마 설명 갱신**: `TERMINAL_SCHEMA`의 `description`을 「허용된 프로그램만 셸 없이 실행한다」는 취지로 고쳐 모델이 제약을 알게 한다.
6. **01편 갱신**: Q3의 「터미널은 걸러내지 않는다」, 0장 마지막 문단, 3부 방어선 4와 「지금은 없는 방어선」, 5부 ① 터미널 행, ③ 터미널 행(타임아웃·절단 시험이 생김)을 고친다. `기준 커밋`은 건드리지 않는다.

## 3. 인수 테스트 시나리오 (구현 전 작성, 임의 변경 금지)

임시 폴더에서 실행한다 (작업 폴더 지정은 050에서 추가되므로, 이 단계의 시험은 현재 작업 폴더를 임시 폴더로 바꿔서 한다).

| # | 입력 (`terminal_tool(command)`) | 기대 결과 |
|---|---|---|
| 1 | `echo hello` | `success` true, `stdout == "hello\n"` |
| 2 | `echo 'a b'` | `stdout == "a b\n"` (따옴표는 인자 묶음에만 쓰임) |
| 3 | `echo a; touch marker` | `stdout == "a; touch marker\n"`, 임시 폴더에 `marker` 없음 |
| 4 | `echo hello`, 공백, 파이프 문자, 공백, `cat` 순서로 이어 쓴 명령 | `stdout`이 `hello`, 공백, 파이프 문자, 공백, `cat`, 줄바꿈 (파이프로 해석되지 않고 글자 그대로) |
| 5 | `echo $HOME` | `stdout == "$HOME\n"` (치환 없음) |
| 6 | `echo $(whoami)` | `stdout == "$(whoami)\n"` |
| 7 | `rm -rf x` (임시 폴더에 파일 `x`를 먼저 만듦) | `success` false, 오류에 `rm` 포함, 파일 `x` 그대로 존재 |
| 8 | `python -c 'print(1)'` | `success` false, 오류에 `python` 포함 |
| 9 | `sudo ls` | `success` false, 오류에 `sudo` 포함 |
| 10 | `/bin/ls` | `success` false (경로 붙은 이름 거부) |
| 11 | `echo 'unterminated` | `success` false, 오류에 `parse` 포함, 예외 없음 |
| 12 | `""` 또는 공백만 | 기존과 같은 `Command cannot be empty.` |
| 13 | `cat` (인자 없음) | 시간 제한 안에 즉시 끝남. `success` true, `stdout == ""` |
| 14 | 임시 폴더에 20,000자 파일 `big.txt`를 만들고 `cat big.txt` | `stdout`이 10,000자 + 절단 안내 문구로 끝남 |
| 15 | 허용 프로그램 실행이 시간 초과 (`subprocess.run`을 `TimeoutExpired`를 던지는 가짜로 교체) | `success` false, 오류에 `timed out` 포함, `exit_code == -1` |
| 16 | `ls missing_file` (종료 코드 비정상) | `success` false, `exit_code != 0`, `stderr`에 내용 |
| 17 | 기존 e2e 터미널 테스트 | 수정 없이 통과 (`echo` 사용) |

## 4. 검증 기준 (Done 조건)

1. `test_terminal_tool.py`의 17개 시나리오(17번은 기존 테스트)가 통과한다.
2. 기존 테스트(010~030 포함)가 모두 통과한다.
3. `grep -n "shell=True" src/hermes_core/tools/terminal_tool.py`의 결과가 없다.
4. `grep -n "ALLOWED_COMMANDS" src/hermes_core -r`로 허용목록 정의가 한 곳뿐임을 확인한다.
