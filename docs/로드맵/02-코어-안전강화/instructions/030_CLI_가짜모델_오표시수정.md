## 1. 구현 내용 명세

1. **실제 모델이 없을 때의 동작** ([`cli.py`](../../../../src/hermes_core/cli.py) `main`):
   - 지금은 실제 모델 클라이언트가 없다. `--mock` 없이 실행하면 에이전트를 만들기 **전에** 표준 오류로 안내 문구를 출력하고 종료 코드 2로 끝낸다.
   - 안내 문구에는 `--mock`과 「실제 모델 클라이언트가 아직 없다」는 취지가 들어간다.
   - 이때 세션 DB와 기억 폴더를 만들지 않는다 (에이전트 생성 전 종료).
2. **`--mock` 동작은 바꾸지 않는다.**
3. **01편 갱신**: 3부 「지금은 없는 방어선」의 CLI 설명, 3부 다이어그램의 「지금은 가짜 모델만 연결됨」 문구를 현재 동작에 맞게 고친다. `기준 커밋`은 건드리지 않는다.

## 3. 인수 테스트 시나리오 (구현 전 작성, 임의 변경 금지)

환경변수 `HERMES_HOME`을 임시 폴더로 지정하고, `sys.argv`를 바꿔 `main()`을 호출한다.

| # | 입력 | 기대 결과 |
|---|---|---|
| 1 | 인자 없음 (`--mock` 없음) | `SystemExit`, 종료 코드 2 |
| 2 | 시나리오 1의 표준 오류 | `--mock` 문자열 포함 |
| 3 | 시나리오 1 이후 임시 `HERMES_HOME` | `state.db`가 생성되지 않음 |
| 4 | `--mock` (`sys.stdin`을 `isatty()`가 False인 가짜 입력으로 고정. 실행 환경에 기대지 않는다) | 정상 종료. 표준 출력에 `Mock session finished cleanly.` 포함 |
| 5 | 시나리오 4의 표준 출력 | `MOCK mode` 안내 포함 (기존 표시 유지) |
