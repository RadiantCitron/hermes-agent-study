> **상위 대시보드**: [06-README.md](../README.md)

> **성격**: 시스템 지시문(모든 대화의 앞부분)을 건드리는 유일한 단계다. 한 번만, 안내문 한 덩어리만 더한다.

---

## 1. 구현 내용 명세

1. **`SKILLS_GUIDANCE`** ([`prompt_builder.py`](../../../../src/hermes_core/agent/prompt_builder.py)): 기존 `MEMORY_GUIDANCE`·`SESSION_SEARCH_GUIDANCE`와 같은 문체의 영어 한두 문장 상수. 내용: 반복되는 절차가 파일로 저장돼 있을 수 있으니, 작업을 시작하기 전에 `skills_list`로 이름과 설명을 보고, 맞는 것이 있으면 `skill_view`로 읽고 따르라. 스킬은 읽기 전용 참고 문서다. **스킬 이름·목록을 안내문에 넣지 않는다**(목록은 도구로만 본다).
2. **연동** ([`agent.py`](../../../../src/hermes_core/agent/agent.py)): `_build_system_prompt`의 `tools_guidance`를 `[MEMORY_GUIDANCE, SESSION_SEARCH_GUIDANCE, SKILLS_GUIDANCE]`로 바꾼다. import에 `SKILLS_GUIDANCE` 추가. 조립 순서·캐시·`sessions.system_prompt` 기록은 그대로다.
3. **작동원리 갱신**: 없음 (050에서 일괄 반영).

## 2. 변경할 파일 목록

- `src/hermes_core/agent/prompt_builder.py` (수정), `src/hermes_core/agent/agent.py` (수정)
- `tests/test_hermes_core/test_skills_guidance.py` (신규)
- `docs/로드맵/06-스킬-시스템-MVP/README.md`, `docs/인계.md` (갱신)

> **사전 점검 (착수 시)**: 안내문 추가는 시스템 프롬프트를 바꾸므로, 먼저 기존 시험 중 시스템 프롬프트의 **리터럴 문자열**이나 길이를 직접 단언하는 것이 있는지 `grep`한다(계획 검토 때 확인: 안내문 상수를 import해 위치만 보는 `test_prompt_builder.py`와, 같은 실행 안에서 캐시·DB 값끼리 비교하는 시험들뿐이며 `tools_guidance`를 만드는 곳은 `agent.py` 한 곳). 있으면 임의로 고치지 않고 멈춰서 보고한다. 그다음 전체 테스트를 변경 전에 한 번 실행해 기준선을 기록한다.
>
> **시험 격리**: 에이전트가 시스템 프롬프트에 작업 디렉터리의 지시문 파일(`AGENTS.md` 등)을 넣으므로, 신규 시험은 `monkeypatch.chdir(tmp_path)`와 `HERMES_HOME` 임시 폴더로 레포의 `AGENTS.md`와 실제 `.hermes`가 섞이지 않게 한다.

## 3. 인수 테스트 시나리오 (구현 전 작성, 임의 변경 금지)

시험 방식: `MockLLMClient`와 임시 DB·기억 폴더로 `HermesAgent`를 만들고(키·네트워크 없음), `HERMES_HOME`을 임시 폴더로 바꾼다.

| # | 입력 | 기대 결과 |
|---|---|---|
| 1 | `SKILLS_GUIDANCE` | 비어 있지 않은 문자열이며 `skills_list`와 `skill_view`를 둘 다 포함, 길이 600자 이하(안내문 한 덩어리) |
| 2 | `build_system_prompt(tools_guidance=[MEMORY_GUIDANCE, SESSION_SEARCH_GUIDANCE, SKILLS_GUIDANCE])` | 결과 문자열에서 세 안내문이 이 순서로 나타남 |
| 3 | 에이전트의 `_build_system_prompt()` 결과 | `SKILLS_GUIDANCE` 포함, `session_db`에 기록된 `sessions.system_prompt`와 같음 |
| 4 | 같은 에이전트에서 `_build_system_prompt()`를 두 번 호출하는 사이에 스킬 폴더에 새 스킬을 추가 | 두 결과가 같은 문자열 (세션 중 불변, 캐시) |
| 5 | 스킬 이름이 `zz-unique-skill-name`인 스킬이 있는 경우와 없는 경우 | 두 경우 시스템 프롬프트가 같고, 그 이름이 프롬프트에 **없음** (목록을 지시문에 넣지 않음) |
| 6 | 에이전트의 도구 스키마 이름 집합 | 기존 6종과 `skills_list`, `skill_view`를 모두 포함 (8종) |
| 7 | 에이전트가 1턴을 실행해 얻은 `result["messages"]`(첫 요소가 **에이전트가 만든** 시스템 메시지)에 긴 user/assistant 쌍을 덧붙여 이력으로 삼고, 낮춘 `context_window_tokens`로 2턴을 실행해 압축을 발동 | 압축 후 모델 호출의 `messages[0]`이 `role == "system"`이고 `SKILLS_GUIDANCE`를 포함하며 1턴의 시스템 메시지와 **바이트 동일**. (이력에 임의의 `"Sys"` 시스템 메시지를 넣으면 안내문이 들어갈 일이 없어 시험이 무효가 된다) |
| 8 | 기존 코어 테스트(05 마감 시점 전체, `test_prompt_builder.py` 포함) | **수정 없이** 통과 |
